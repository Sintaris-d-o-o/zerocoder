## Тема урока

Создашь работающий генератор постов для Telegram: от внешнего POST-запроса → к генерации текста через OpenAI → к автоматической публикации в канал через n8n.

У тебя будет готовая архитектура автопостинга, которую можно масштабировать: добавить генерацию изображений, подключить бота как интерфейс управления и превратить это в полноценный кейс для портфолио.

Продолжим изучение курса по промпт-инжинирингу и работу над блоком уроков, посвящённых созданию кейсов для портфолио. Создадим генератор постов для Telegram. Для реализации используем n8n как рабочий инструмент для автоматизации задач и создания workflow — рабочих процессов, которые будут работать так, как нам нужно.



Сегодня мы:

Изучим n8n, как рабочий инструмент для автоматизации задач.
Изучим как мы можем делать запросы к телеграм через API.
Напишем небольшой n8n скрипт для автопостинга в телеграм используя openai.

## Домашнее задание
В этом задании вы самостоятельно соберёте и протестируете систему автопостинга в Telegram через n8n с подключением OpenAI по API.



🔹 Что нужно сделать
1️⃣ Развернуть n8n
Установить Docker Desktop.
Скачать образ n8nio/n8n.
Создать Volume для хранения данных.
Запустить контейнер в фоновом режиме (d).
Убедиться, что n8n доступен по адресу http://localhost:5678.


2️⃣ Создать рабочий Workflow
Соберите цепочку:

Webhook (POST) → AI (Message a model) → HTTP Request (Telegram API)

Обязательно:

В Webhook настроить метод POST.
Передавать параметр topic через JSON.
В AI-модуле использовать динамическую переменную из входящего запроса.
Корректно обратиться к вложенной структуре ответа модели (с индексами [0]).


3️⃣ Подключить Telegram-бота
Создать бота через BotFather.
Создать Telegram-канал.
Добавить бота в канал и выдать права администратора.
Настроить отправку сообщения через chat_id, text, parse_mode=HTML.


4️⃣ Протестировать систему
Написать небольшой Python-скрипт с POST-запросом на ваш Webhook.
Передать тему поста (например: "AI в маркетинге").
Проверить успешное выполнение (status_code 200).
Убедиться, что пост автоматически опубликован в Telegram-канале.


📌 В каком виде сдать задание
В качестве отчёта необходимо предоставить:

Скриншот запущенного контейнера n8n в Docker (статус Running).
Скриншот схемы Workflow в n8n (вся цепочка целиком).
Скриншот раздела Executions с успешным выполнением (Status: Success).
Скриншот опубликованного поста в Telegram-канале.
Файл main.py (или скриншот кода) с POST-запросом.
