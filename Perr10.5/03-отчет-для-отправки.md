## Что сделано

Собран автопостинг в Telegram на n8n: внешний POST-запрос с темой поста → генерация
текста моделью (`gpt-4o-mini` через узел «Message a model») → публикация в
Telegram-канал через Bot API.

n8n развёрнут в Docker (контейнер `n8n-new`, образ `n8nio/n8n:2.39.8`, том для
данных, автоматический перезапуск) и открыт наружу по адресу
**https://sintaition.sintaris.net** — не только `localhost`, чтобы вебхук был
доступен снаружи по-настоящему. Проверено запросом с постороннего сервера
(VPS в Германии): ответ пришёл за 3,3 секунды, пост опубликован.

## Проверка одним запросом

```bash
curl -X POST https://sintaition.sintaris.net/webhook/zerocoder-autopost \
  -H "Content-Type: application/json" \
  -d '{"topic": "Тема поста"}'
```

Ответ содержит прямую ссылку на опубликованный пост.
