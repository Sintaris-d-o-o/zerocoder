# RAG-система для виртуального консультанта по ювелирным изделиям

## Задание

Разработать локальную RAG-систему (Retrieval-Augmented Generation) для консультирования по ювелирным изделиям.

### Требования:

1. **Подготовка документов:**
   - Использовать документы из папки `Ювелир` или создать свои
   - Документы должны содержать информацию о ювелирных изделиях, уходе за ними, рекомендациях

2. **Настройка базы данных:**
   - Интегрировать Faiss и ChromaDB для хранения и поиска векторных представлений
   - Загрузить подготовленные документы в выбранную базу
   - Протестировать качество поиска

3. **Настройка модели:**
   - Использовать Llama3 или аналог для локальной генерации текстов
   - Убедиться, что модель запускается локально без облачных сервисов

4. **Реализация RAG-цепочки:**
   - Создать систему извлечения релевантных документов
   - Реализовать генерацию ответов на основе найденных документов
   - Обеспечить правильное форматирование запросов и ответов

5. **Тестирование системы:**
   - Тестовые запросы:
     - "Как ухаживать за золотыми изделиями?"
     - "Посоветуй кольцо с бриллиантом"
     - "Какие материалы используются в ювелирном деле?"
     - "Как чистить серебро?"
   - Проверить точность извлечения данных
   - Оценить релевантность рекомендаций

6. **Отчет и публикация:**
   - Написать краткий отчет о сравнении Faiss и ChromaDB
   - Указать, какая база данных дала лучшие результаты и почему
   - Опубликовать код на GitHub в публичном репозитории
   - Убедиться, что код полностью локальный и работает без интернета

## Ключевые компоненты

- **Document Loader**: загрузка и предобработка документов
- **Vector Store**: интеграция с Faiss/ChromaDB
- **RAG Pipeline**: цепочка retrieval + generation
- **Local LLM**: Llama3 через Ollama или LlamaCpp
- **Testing Suite**: проверка качества ответов
