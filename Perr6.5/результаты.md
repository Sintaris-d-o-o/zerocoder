# Результаты — Perr6.5: локальный RAG-консультант по ювелирным изделиям

## Что сделано простыми словами

Собрали небольшого ИИ-консультанта, который отвечает на вопросы про уход за ювелирными
изделиями и их выбор — не выдумывая ответ, а опираясь на реальные памятки (документы из
папки `data/Ювелир`). Всё считается на локальном компьютере: и поиск нужного текста, и
формулировка ответа — без ChatGPT, без облачных сервисов, без интернета (кроме
однократного скачивания программ и моделей при установке).

Для поиска подходящих кусочков текста сделали **две** версии — на FAISS и на ChromaDB — и
сравнили их между собой в отдельном отчёте.

Систему проверили на всех 4 вопросах из задания на обеих базах (8 прогонов) — ответы
получились по делу, основаны на содержимом документов, без придуманных фактов.

## Неожиданности по пути (и как их обошли)

- **Файлы в исходной папке были перепутаны по расширениям**: два файла с расширением
  `.pdf` на самом деле оказались Word-документами, а один файл `.docx` — обычным PDF,
  другой `.docx` — простым текстовым файлом. Загрузчик документов теперь определяет
  реальный тип файла по содержимому, а не по имени — иначе часть документов просто не
  прочиталась бы.
- **Библиотека FAISS не смогла сохранить файл на диск** из-за того, что путь к проекту
  содержит кириллицу (папка `Проекты`) — это особенность старой C++-библиотеки на Windows.
  Обошли, сохранив индекс через промежуточный шаг в памяти.
- **Маленькая модель иногда "зацикливалась"** — на одном из вопросов ответ превратился в
  бесконечный список одних и тех же слов. Добавили ограничение длины ответа и штраф за
  повторы — после этого все 8 тестовых ответов получились чистыми и по делу.

Подробности всех трёх находок — в `.claude/skills/zerocoder-task/LESSONS-LEARNED.md`
рабочего репозитория (пригодится для следующих заданий).
