# Демонстрация

## Как посмотреть результат без установки чего-либо

Самый быстрый способ — открыть готовый лог прогона тестовых вопросов
[tests/test-results.md](tests/test-results.md): там сохранены все 4 вопроса из задания,
ответы модели и найденные фрагменты документов для обеих баз (FAISS и ChromaDB), а также
сравнение в [REPORT.md](REPORT.md).

## Как запустить у себя (для проверяющего)

1. Установить [Ollama](https://ollama.com/download) и скачать модель:
   ```bash
   ollama pull llama3.2:3b
   ```
2. Создать окружение и поставить зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   pip install -r requirements.txt
   ```
3. Построить векторные базы:
   ```bash
   python -m src.vector_store
   ```
4. Задать вопрос:
   ```bash
   python -m src.main "Как ухаживать за золотыми изделиями?"
   ```
5. (Опционально) прогнать все тестовые вопросы заново:
   ```bash
   python -m tests.test_queries
   ```

Подробности — в [README.md](README.md).
