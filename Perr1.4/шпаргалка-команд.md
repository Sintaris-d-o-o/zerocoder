# Шпаргалка: задание 1.4 своими руками

Все команды — для терминала **Git Bash** на Windows (Пуск → Git Bash). Если
хотите повторить с нуля, сначала удалите старую папку: `rm -rf ~/cli_practice`.

## 1. Структура проекта

```bash
cd ~                          # перейти в домашнюю папку
pwd                           # где я? → /c/Users/souls
mkdir cli_practice            # создать папку проекта
cd cli_practice
mkdir app logs .config        # три папки; .config скрытая из-за точки в начале
touch README.txt app/main.py  # два пустых файла
pwd
ls -a                         # -a показывает и скрытые (.config)
ls -R                         # всё дерево папок
```

**Скриншот 1** — после `ls -R`.

## 2. Код скрипта

Текст скрипта — в [cli_practice/app/main.py](cli_practice/app/main.py). Вставить его
в файл можно прямо из терминала:

```bash
cat > app/main.py <<'EOF'
...вставить сюда текст скрипта...
EOF
```

## 3. Виртуальное окружение и запуск

```bash
python -m venv .venv               # создать окружение
source .venv/Scripts/activate      # включить; в начале строки появится (.venv)
which python                       # должно быть .../cli_practice/.venv/Scripts/python
python --version
python app/main.py                 # запуск — в терминале появятся 4 записи
deactivate                         # выключить окружение
```

На Linux и Mac команда включения другая: `source .venv/bin/activate`.

**Скриншот 2** — после `deactivate`.

## 4. Журнал

```bash
cat logs/app.log                       # весь журнал
grep -E "WARNING|ERROR" logs/app.log   # только предупреждения и ошибки
```

**Скриншот 3** — после `cat logs/app.log`.
