# Как показать задание 1.4

## Что отправить проверяющему

1. Три скриншота из папки [screenshots/](screenshots/):
   - `1-структура-проекта.png` — создание папок и файлов, `pwd`, `ls -a`, `ls -R`;
   - `2-запуск-скрипта.png` — создание и включение `.venv`, версия Python, запуск,
     выключение окружения;
   - `3-содержимое-app-log.png` — `cat logs/app.log` и поиск предупреждений и ошибок.
2. Краткое описание — раздел «Краткое описание» в [результаты.md](результаты.md).
3. По желанию — ссылку на папку `Perr1.4` в репозитории GitHub: там код, настоящий
   журнал и полный текст всех команд.

## Как это было снято

Все команды выполнены в Git Bash на этом компьютере; полный их вывод записан в
папку [протокол/](протокол/). Картинки сделаны из этого вывода скриптом
[make_screenshots.py](make_screenshots.py): он оформляет текст как окно терминала и
снимает его браузером Edge без открытия окна. Пересоздать картинки:

```bash
python make_screenshots.py
```

Если нужны снимки собственного экрана — пройдите [шпаргалку команд](шпаргалка-команд.md),
это около 5 минут.

## Показать вживую

```bash
cd ~/cli_practice
source .venv/Scripts/activate
python app/main.py
deactivate
cat logs/app.log
```

Каждый запуск **дописывает** в журнал ещё четыре записи — так видно, что файл
копит историю, а окно терминала нет.
