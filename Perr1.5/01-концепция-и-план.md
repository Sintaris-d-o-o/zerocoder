# Perr1.5 — концепция и план (итоговая редакция)

## Решение пользователя

1. Новый сервер не создаём и для задания к серверам не подключаемся. Сдаём **отчёт по уже
   сделанному**.
2. Отчёт строим вокруг VPS **dev2null.de**: этот сервер уже фигурировал в сданных
   заданиях 7.1 и 10.5.

Отклонённые варианты (были в предыдущих редакциях): новый учебный VPS у Timeweb/Beget;
живой прогон на VPN-узле si-node; описание «VPS в Германии» без привязки к конкретному серверу.

## Из чего собирается отчёт

| Пункт задания | Источник |
|---|---|
| 1–2. Параметры и VPS | документация dev2null.de (`sintaris-srv`), замер памяти из Perr9.2 |
| 3. SSH | журнал закрытия входа по паролю (11.09.2026), задания 7.1 и 10.5 |
| 4. Обновления, Python | `unattended-upgrades`, аудит обновлений 28.08.2026; Python в 7.1 и 10.5 |
| 5–6. Python-файл, ошибки | Perr7.1 (`stt_service.py`, семь исправленных проблем), Perr10.5 (`main.py`) |

Выдержки из закрытой документации копируются в `results/` без IP, паролей и ключей.
Службы из Perr10.4 работают на домашнем сервере, а не на VPS, поэтому в доказательства
по VPS не берём.

## Проверка

Каждая ссылка ведёт на существующий файл, каждый факт есть в источнике, на каждом
доказательстве ясно, с какого сервера оно снято.
