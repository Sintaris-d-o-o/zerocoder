# Perr1.5. Первый сервер (VPS) и запуск Python-кода на нём

Оригинал урока: `university.zerocoder.ru`, модуль 1. Текст задания вставлен пользователем в чат.

## Домашнее задание

Разверни свой первый сервер и запусти на нём Python-код 🚀

Что нужно сделать:

### 1️⃣ Определить параметры сервера

Перед созданием сервера зафиксируй базовые решения:

- Определи тип проекта (например: бот, сайт, API или тестовый запуск)
- Выбери:
  - локацию сервера
  - конфигурацию (CPU, RAM, диск)
- Кратко объясни, почему выбрал именно такие параметры

📌 Важно: ориентируйся на логику из урока (не бери «с запасом», а под задачу)

### 2️⃣ Создать VPS у хостинг-провайдера

- Зарегистрируйся у любого провайдера (например, Beget / Timeweb / другой)
- Создай виртуальный сервер (VPS)
- Выбери:
  - Linux (например, Ubuntu)
  - минимальную конфигурацию
- Дождись создания сервера

📌 После создания у тебя должны быть: IP-адрес, логин, пароль

### 3️⃣ Подключиться к серверу через SSH

Через терминал:

- Подключись к серверу командой: `ssh root@IP-адрес`
- Подтверди подключение
- Введи пароль

📌 Если не получилось — попробуй ещё раз или подожди (сервер может не сразу запуститься)

### 4️⃣ Подготовить сервер к работе

После подключения:

- Выполни команды:
  - `apt update`
  - `apt upgrade`
- Проверь установлен ли Python: `python3 --version`

### 5️⃣ Создать и запустить первый Python-файл

В терминале:

- Создай файл через nano
- Напиши код:

```python
print("Hello, World!")
print("My first server!")
```

- Сохрани файл
- Проверь содержимое через: `cat имя_файла.py`
- Запусти файл: `python3 имя_файла.py`

### 6️⃣ Проверить работу сервера

- Убедись, что код успешно выполнился
- Если возникли ошибки — попробуй их исправить

## Формат сдачи

Необходимо предоставить:

1️⃣ Скриншоты:

- созданного сервера (панель провайдера с IP)
- успешного подключения по SSH
- выполнения команд apt update / apt upgrade
- проверки версии Python
- запуска Python-файла с выводом в терминале

2️⃣ Краткое описание (5–10 предложений):

- какой тип сервера выбрал и почему
- какую конфигурацию использовал
- что оказалось самым сложным при подключении
- зачем нужен SSH
- чем VPS лучше локального сервера для реальных проектов

📌 Результат: у тебя должен быть рабочий удалённый сервер и первый запущенный код на нём.
