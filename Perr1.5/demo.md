## Если нужны живые скриншоты (необязательно, около 5 минут)

Снимать в обычном окне терминала на ноутбуке владельца. Команды ничего не меняют
в работе VPN:

1. **Панель провайдера.** Личный кабинет NEOSERV, карточка сервера с IP `152.89.233.180`.
2. **SSH.** `ssh si-node`, затем `hostname; uptime`.
3. **Обновления.** `sudo apt update`, затем `apt list --upgradable`.
   Полный `sudo apt upgrade` делать только в спокойное время, и сразу после него выполнить
   `systemctl is-active x-ui nginx` (оба должны ответить `active`) и
   `ls /var/run/reboot-required` (если файл есть, серверу нужна перезагрузка; планировать её
   отдельно, это минута без VPN).
4. **Python.** `python3 --version`.
5. **Первый файл.**
   ```
   mkdir -p ~/zerocoder && cd ~/zerocoder
   nano hello.py        # две строки: print("Hello, World!") и print("My first server!")
   cat hello.py
   python3 hello.py
   ```
6. Положить кадры в `Perr1.5/results/screenshots/` и добавить их в список приложений
   в [ответ-для-отправки.md](ответ-для-отправки.md).

Если что-то из этого выполнялось на сервере, сеанс нужно записать в журнал
`sintaris-srv/vps-admin/docs/vps-activity-log.md`: таково правило администрирования серверов.
