# Как сдать задание 1.5

1. Отправить проверяющему текст из [ответ-для-отправки.md](ответ-для-отправки.md).
2. Приложить как доказательства:
   - [results/выдержки-dev2null.md](results/выдержки-dev2null.md): параметры сервера,
     аудит обновлений, журнал закрытия входа по паролю;
   - [../Perr7.1/02-развертывание.md](../Perr7.1/02-развертывание.md): Python-сервис на этом VPS;
   - [../Perr10.5/результаты.md](../Perr10.5/результаты.md): запуск `main.py` с VPS.
3. По желанию: скриншот панели Netcup (servercontrolpanel.de, карточка сервера) с
   закрашенным IP. Это делается в браузере и к серверу не подключается.

Доступ к серверу проверяющему не выдаём: на нём почта, n8n и боты клиентов.

## Если проверяющий потребует живые кадры терминала

Делает владелец сервера. Команды ничего не меняют:

```
ssh stas@dev2null.de
hostname; uptime
apt list --upgradable 2>/dev/null | wc -l
ls /var/run/reboot-required 2>/dev/null || echo "перезагрузка не нужна"
python3 --version
mkdir -p ~/zerocoder && cd ~/zerocoder && nano hello.py
cat hello.py && python3 hello.py
```

`sudo apt upgrade` на этом сервере вручную не запускать: это делается только в окно
обслуживания, с записью в журнал `sintaris-srv`.

Перед отправкой проверить, что на картинках нет IP-адресов, паролей и токенов.
