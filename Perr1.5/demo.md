# Как сдать задание 1.5

1. Отправить проверяющему текст из [03-отчет-для-отправки.md](03-отчет-для-отправки.md):
   параметры сервера, таблицу «где выполнено» и краткое описание.
2. Приложить как доказательства:
   - вывод `systemctl status` со служб Taris на Python (домашний сервер) — [Perr10.4/results/services.txt](../Perr10.4/results/services.txt);
   - скриншоты задания 10.5 (n8n на сервере, выполнение, пост в канале) — [Perr10.5/results/screenshots/](../Perr10.5/results/screenshots/);
   - скриншоты терминала из задания 1.4 — [Perr1.4/screenshots/](../Perr1.4/screenshots/).
3. По желанию — скриншот панели провайдера с закрашенным IP.

Перед отправкой проверить, что на приложенных картинках нет IP-адресов, паролей и токенов.
