## 1. Обзор сайта и документации LangChain

У сайта LangChain недавно появилась версия 0.3. В версии 0.1 информация представлена более подробно: https://python.langchain.com/v0.1/docs/modules/

**Разделы блока слева (v0.1):**
- **Model I/O** — модели и всё, что связано с подключением языковых моделей, промпты, настройки чатов, парсер выходных параметров.

19. Режим стрима (ответ приходит частями, не дожидаясь полной генерации):
```python
chat = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)
for chunk in chat.stream("Напиши тезисы про важность промпт-инжиниринга"):
    print(chunk.content, end="", flush=True)
```
Причины использовать стрим: мгновенный старт ответа, лучше UX, экономия времени пользователя, возможность раннего прерывания, оптимизация ресурсов, интерактивность, удобство для длинных ответов, удобство мониторинга/логирования в реальном времени.

## 3. Взаимодействие с языковыми моделями: Часть 2 — структурированные данные

1. Извлечение структурированных данных из текста через Pydantic-модель и парсер:
```python
from langchain_openai import ChatOpenAI
from langchain.output_parsers import PydanticOutputParser
from langchain_core.prompts import PromptTemplate
from pydantic import BaseModel, Field
from typing import List

class Person(BaseModel):
    name: str = Field(description="Полное имя человека")
    age: int = Field(description="Возраст человека")
    hobbies: List[str] = Field(description="Список хобби")

parser = PydanticOutputParser(pydantic_object=Person)
```
Такую конструкцию можно использовать и для парсинга заказов — модель формирует и валидирует структурированные данные по заданной схеме.

2. Промпт + цепочка:
```python
prompt = PromptTemplate(
    template="Extract structured information from the following text:\n{text}\n{format_instructions}",
    input_variables=["text"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)
chain = prompt | model | parser
text = """
Иван Иванов - 32-летний инженер-программист. Он любит играть на гитаре,
ходить в походы по выходным и экспериментировать с новыми кулинарными рецептами.
"""
result = chain.invoke({"text": text})
print(result)  # получаем структурированный JSON
```

3–4. Обращение к полям результата:
```python
print(f"Name: {result.name}")
print(f"Age: {result.age}")
print(f"Hobbies: {', '.join(result.hobbies)}")
```

5. Режим отладки вместо LangSmith:
```python
from langchain.globals import set_debug

```

Пример суммаризации текста через классическую `LLMChain`:
```python
from langchain_openai import OpenAI
from langchain.chains import LLMChain
from langchain.prompts import PromptTemplate

llm = OpenAI(temperature=0, max_tokens=3000)
prompt_template = """
Пожалуйста, подведите итог следующему тексту:
{text}
"""
prompt = PromptTemplate(input_variables=["text"], template=prompt_template)
llm_chain = LLMChain(llm=llm, prompt=prompt)
summary = llm_chain.run(text=text)
print(summary)
```

**Few-shot в промпте** — примеры не только показывают ожидаемый формат ответа, но и задают логику рассуждений (пошаговые вопрос-ответ цепочки типа "Follow up ... Intermediate answer ... final answer"):
```python
from langchain_core.prompts.few_shot import FewShotPromptTemplate
from langchain_core.prompts.prompt import PromptTemplate

examples = [
    {"question": "Who lived longer, Muhammad Ali or Alan Turing?", "answer": "..."},
    {"question": "When was the founder of craigslist born?", "answer": "..."},
    {"question": "Who was the maternal grandfather of George Washington?", "answer": "..."},
    {"question": "Are both the directors of Jaws and Casino Royale from the same country?", "answer": "..."},
]

example_prompt = PromptTemplate(
    input_variables=["question", "answer"], template="Question: {question}\n{answer}"
)

prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    suffix="Question: {input}",
    input_variables=["input"],
)
chain = prompt | model
chain.invoke({"input": "Как звали супруг первого президента Российской Федерации?"})
```

## 4. ReAct и FuncCalls (Tool Calling Agent)

Два подхода к реализации агентов:
- **ReAct** — больше пространства для разработчика, можно заложить любую логику действий; чуть сложнее, но гибче.
- **Tool Calling Agent (Function Calling)** — выбираем функции и переменные заранее, работа в более жёстких рамках.

**Пример — спланировать поездку.**

*Tool Calling Agent:* определяются инструменты `search_flights(origin, destination, date)`, `book_flight(flight_id, passenger_details)`, `get_weather(location, date)` → схема отдаётся LLM → пользователь спрашивает → LLM решает вызвать нужный инструмент с параметрами → результат отображается.

*ReAct:* разработчик пишет ReAct-промпт с шагами (определить пункты, даты, искать рейсы, проверить погоду, забронировать) → LLM генерирует план действий по одному шагу → выполняет действие → анализирует наблюдение → генерирует следующее действие → повторяется итеративно до достижения цели.

### Реализация: Function Calling (Tool Calling Agent)

Установка: `!pip install langchain-community`, `!pip install pyowm`. Ключ Tavily — https://app.tavily.com (регистрация через Google). Ключ OpenWeatherMap — https://openweathermap.org (раздел API → генерация ключа).

```python
from langchain.agents import AgentExecutor, create_openai_functions_agent
from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_community.utilities import OpenWeatherMapAPIWrapper
from langchain.tools import Tool
from langchain.prompts import ChatPromptTemplate
from langchain.chat_models import ChatOpenAI
import os

os.environ["TAVILY_API_KEY"] = 'добавить API'
os.environ["OPENWEATHERMAP_API_KEY"] = 'добавить API'

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "You are a helpful assistant"),
        ("placeholder", "{chat_history}"),
        ("human", "{input}"),
        ("placeholder", "{agent_scratchpad}"),
    ]
)

weather = OpenWeatherMapAPIWrapper()
weather_tool = Tool(
    name="Weather",
    func=weather.run,
    description="Useful for getting weather information"
)
tools = [TavilySearchResults(max_results=7), weather_tool]

model = ChatOpenAI(temperature=0.7)
agent = create_openai_functions_agent(model, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

response = agent_executor.invoke({"input": "будет ли в Москве дождь?"})
response = agent_executor.invoke({"input": "Какие интересные места для отдыха в Италии?"})
response = agent_executor.invoke({"input": "Есть ли в жизни счастье?"})  # без вызова инструментов
```
Проверка выдачи — в LangSmith.

### Реализация: подход ReAct

Цикл агента: Action (выбор инструмента) → Action Input (данные в инструмент) → Observation (наблюдение за ответом) → Thought (вывод); повторяется N раз до финального ответа.

```python
from langchain import hub
from langchain.agents import AgentExecutor, create_react_agent
from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_openai import OpenAI

prompt = hub.pull("hwchase17/react")
# Готовый ReAct-промпт задаёт формат:
# Question / Thought / Action / Action Input / Observation (повторяется) / Thought / Final Answer

agent = create_react_agent(model, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
agent_executor.invoke({"input": "будет ли в Москве дождь?"})
```

**Сравнение в LangSmith:** ReAct-агент делает больше промежуточных вызовов модели (видно явный цикл размышлений — Thought/Action/Observation), чем Function Calling — заметна разница и во времени генерации, и в стоимости запроса. Function Calling быстрее и дешевле там, где заранее известен чёткий набор инструментов; ReAct гибче, когда логика действий заранее не фиксирована.
