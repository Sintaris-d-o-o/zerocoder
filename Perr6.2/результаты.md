# Результаты — Perr6.2 LangChain Cookbook

## Что сделано простыми словами

Изучил раздел «Cookbook» открытого учебника LangChain OpenTutorial (https://langchain-opentutorial.gitbook.io/langchain-opentutorial/19-cookbook) — уточнённую ссылку, которую дал пользователь взамен устаревшей ссылки из конспекта урока. Подробно разобрал код готовой сборки **«New Employee Onboarding Chatbot»** — бота, который отвечает новым сотрудникам на вопросы по базе знаний компании (документы в Notion), причём в трёх нарастающих по сложности версиях: простой поиск-и-ответ → добавление проверки релевантности найденных документов → добавление разбиения сложного вопроса на подвопросы.

Показал, как ровно ту же схему применить в проекте Тарис: онбординг-бот для новых студентов и экспертов на базе знаний платформы, с постепенным усложнением от простого RAG до фильтрации и разбора составных вопросов.

Готовый ответ для отправки преподавателю — файл `01-ответ-на-домашнее-задание.md` (обновлён и переработан под правильную ссылку).
