# Результаты — Perr7.4

## Что сделано простыми словами

Задание просило собрать в Google Colab поисковик резюме под вакансию — на эмбеддингах и
векторной базе данных. По вашей просьбе мы не стали делать это заново с нуля, а разобрали, **как
эта же по сути задача уже решена в вашей платформе Taris**: там она называется RAG-поиск по базе
знаний и работает не на резюме, а на вашей реальной предметной области — здоровье/нутрициология
(вопрос пользователя → подходящий товар/протокол из справочника).

Результат — документ [`02-как-это-реализовано-в-Taris.md`](02-как-это-реализовано-в-Taris.md):
пошаговое сопоставление задания с реальным кодом Taris (конкретные файлы, функции, настройки) и
два реальных примера из практики бота, показывающих пайплайн в действии на настоящих данных, а не
на придуманном примере.

Новый код не писали и боевой проект `sintaris-pl` не трогали — по вашей же просьбе: «нет цели
реализовывать задачу заново, только показать как она реализована в Taris».

## Сверка с исходным заданием (`00-задание7.4.md`)

| Пункт задания | Статус | Где в Taris (см. подробности в `02-как-это-реализовано-в-Taris.md`) |
|---|---|---|
| Установить библиотеки для векторизации, БД, загрузки документов и таблиц | ✅ Есть | `deploy/requirements.txt`, `EmbeddingService._try_load()` (мягкая загрузка библиотек эмбеддингов) |
| Проверить версии библиотек | ✅ Есть, но иначе | `EmbeddingService` не падает при несовместимости — просто отключает семантический поиск, вместо ручной проверки версий в ноутбуке |
| Перевести текст в векторы бесплатной моделью для русского языка | ✅ Есть, 1:1 | `EMBED_MODEL = paraphrase-multilingual-MiniLM-L12-v2` — открытая, бесплатная, локальная, понимает русский |
| Загрузить базу резюме | ✅ Есть, адаптировано | Загрузка документов (PDF/DOCX/TXT/RTF) в базу знаний — резюме заменены на документы/товарный справочник |
| Взять случайную подвыборку для ускорения | ⚠️ Другой подход | В Taris индексируется вся база целиком (корпус небольшой, работает офлайн); выборка «с запасом» происходит на этапе самого поиска (`top_k * 6` в `search_similar()`), а не при подготовке данных — честно другое решение той же проблемы производительности |
| Просмотреть первые строки, понять структуру данных | ✅ Есть, адаптировано | Admin Panel → список документов: заголовок, число чанков/токенов, дата, превью текста |
| Уникальные значения ключевых колонок, оставить нужные колонки | ✅ Есть, адаптировано | Документы делятся на группы (`guides` / `courses` / `knowledge`) — админ может включать/выключать источники поиска по группам |
| Преобразовать таблицу в текст | ✅ Есть, 1:1, даже лучше | `_flatten_tables()` — автоматически на каждой загрузке/переиндексации, с реальным разобранным дефектом (потеря заголовка таблицы при чанкинге) |
| Доработать и проверить результат (например, первые 100 строк) | ✅ Есть | Фильтр коротких/мусорных фрагментов (`_MIN_CHUNK_CHARS = 20`), метрики качества чанкинга в метаданных документа |
| Указать файл, кодировку, разделитель | ✅ Есть, адаптировано | Определение типа файла и извлечение текста по формату (PDF/DOCX/TXT/RTF), не по расширению файла |
| Разбить текст на блоки и превратить в документы | ✅ Есть, 1:1 | `_chunk_text()` — чанкинг по структуре документа, `RAG_CHUNK_SIZE = 512` |
| Построить векторную базу данных | ✅ Есть, 1:1 | `sqlite-vec` (слабое железо) или `pgvector` (сервер) |
| Настроить поиск, структурировать вывод | ✅ Есть, значительно развитее задания | Гибридный поиск (текстовый + векторный) с объединением через RRF, ответ LLM на основе найденного + подпись с источниками |

**Итог:** все пункты задания имеют прямое соответствие в реальной архитектуре Taris. Часть из них
реализована даже более развито, чем требует учебное задание (гибридный поиск вместо чистого
векторного, автоматическая нормализация таблиц, фильтрация по группам документов) — это
естественно, так как в проде за год накопился опыт реальных проблем поиска, которых не видно на
разовом учебном примере.

Два пункта («случайная подвыборка», «указать кодировку/разделитель файла») реализованы **не
дословно**, а другим, но равноценным по цели способом — честно отмечено в таблице выше.
