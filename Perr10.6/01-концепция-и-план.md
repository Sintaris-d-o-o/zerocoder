# Задание 10.6 — концепция и план

## Что просят

Довести автопостинг из 10.5 до полной версии:

1. **Цепочка**: вебхук → текст поста (с ограничением токенов) → отдельный узел, который
   придумывает промпт для картинки → генерация картинки → отправка в Telegram через
   `sendPhoto` с подписью, с правильной передачей двоичных данных.
2. **Защита**: вебхук закрыт заголовком `Authorization: Bearer <токен>`. Без токена — 403,
   с токеном — 200.
3. **Развёртывание**: всё это на удалённом сервере в Docker, цепочка импортируется из JSON,
   ключи подключаются заново, работает production-адрес.

Сдать: схему цепочки, успешное выполнение, пост с текстом и картинкой, ответ 200, ошибку 403,
файл JSON.

## Что из этого уже есть в нашем продукте

Контент-агент certtaris делает ровно то, что просит урок, — только не в n8n, а кодом.
Всё перечисленное проверено по исходникам `sintaris-pl`:

| Шаг урока | Где это в Taris |
|---|---|
| Генерация текста поста | `src/features/bot_content.py` — через n8n или локальную модель |
| **Отдельный шаг «придумать промпт для картинки»** | `bot_images.describe_image_for_post(post_text, topic, lang)` — отдельная функция, которая читает готовый пост и пишет задание художнику |
| Генерация картинки | `bot_images.generate_image()` — OpenAI, по умолчанию `gpt-image-1`, размер 1024×1024 |
| Отправка фото с подписью | `bot_content.py` — `sendPhoto` с `caption` и `parse_mode` |
| Передача двоичных данных | файл открывается и уходит в `files={"photo": ...}`, картинка хранится локально |
| Защита вебхуков | `WEBHOOK_AUTH_TYPE = none \| bearer \| apikey \| hmac \| basic`, значение в `WEBHOOK_AUTH_TOKEN` |

Два места, где наш код знает больше, чем урок:

**Подпись у фото в Telegram ограничена 1024 знаками**, а у обычного сообщения — 4096.
Урок предлагает просто положить текст в `caption`, и на любом нормальном посте это упадёт.
В Taris это решено так: если текст помещается — он идёт подписью, если нет — сначала уходит
фото без подписи, следом текст отдельным сообщением (`bot_content.py`, `_TG_CAPTION_LIMIT = 1024`).

**Промпт для картинки тоже ограничен** — у `dall-e-3` это 1000 знаков, поэтому в Taris
задание художнику режется до 900. Без этого получаешь не картинку, а ошибку 400.

Оба ограничения перенесём в цепочку n8n — иначе демонстрация будет работать только на
коротких постах.

## Что делаем

Расширяем цепочку из 10.5, а не пишем новую. Получается:

```
Webhook (POST, Header Auth)
  → Prepare Prompt         — задание для модели из параметра topic
  → AI: текст поста        — ограничение токенов
  → Parse Response         — достаём текст, режем под лимит Telegram
  → AI: промпт картинки    — отдельный узел: читает готовый пост, пишет задание художнику
  → Generate Image         — картинка, на выходе двоичные данные
  → HTTP Request: sendPhoto — фото с подписью
  → (если текст длиннее 1024) sendMessage — остаток текста отдельным сообщением
  → Build Result           — ссылка на пост
  → Respond to Webhook
```

Защита: в n8n есть готовый тип учётных данных **Header Auth** — имя заголовка
`Authorization`, значение `Bearer <токен>`. Узел вебхука переключается на него, и n8n сам
отвечает 403 всем, кто пришёл без заголовка. Свой код для этого писать не нужно.

Тема поста остаётся нашей: сертификация медизделий, MDR/IVDR.

## Польза для продукта

Задание даёт повод закрыть настоящий пробел. Сейчас в Taris генерация текста уже ходит в
n8n (`N8N_CONTENT_GENERATE_WH`, включено в прошлом уроке), а **картинка по-прежнему делается
внутри процесса бота**: пока модель рисует, занят рабочий процесс веб-сервиса. Для
certtaris, который и так живёт близко к пределу памяти, это заметно.

Если цепочка «текст → промпт картинки → картинка» переедет в n8n целиком, бот будет только
отдавать задание и забирать результат. Предлагаю сделать это **необязательным**: появится
переменная `N8N_CONTENT_IMAGE_WH`; задана — картинка делается в n8n, пуста — всё работает
как сейчас. Тот же приём, что с генерацией текста, и так же безопасно откатывается.

Если при сборке выяснится, что в цепочку урока приходится тащить что-то чуждое продукту, —
это останется только в учебной цепочке `Zerocoder 10.6`, а в Taris не попадёт.

5. Публикация поста с картинкой в `@business_ai_automate`.
6. `результаты.md`, `demo.md`, скриншоты.
