## Что сделано

Автопостинг из задания 10.5 доведён до полной версии: цепочка n8n сама пишет текст
поста, придумывает задание художнику, рисует картинку (`gpt-image-1-mini`) и
публикует пост с картинкой в Telegram (`sendPhoto`, подпись — текст поста). Вебхук
закрыт токеном (Header Auth): без заголовка `Authorization` n8n отвечает 403 и
даже не запускает цепочку, с правильным токеном — 200 и публикация.

Проверено снаружи, с постороннего сервера (VPS в Германии), через боевой адрес
**https://sintaition.sintaris.net**, а затем повторно подтверждено свежим прогоном:

| Запрос | Ответ | Время |
|---|---|---|
| без заголовка `Authorization` | **403** | 0,2 с |
| с заголовком `Authorization: Bearer …` | **200**, пост с картинкой | 16–16,4 с |

Полный протокол обоих запусков — в [`results/проверка-защиты.txt`](results/проверка-защиты.txt).

## Проверка двумя запросами

```bash
# без токена — должно вернуть 403
curl -i -X POST https://sintaition.sintaris.net/webhook/zerocoder-autopost-image \
  -H "Content-Type: application/json" \
  -d '{"topic": "Тема поста"}'

# с токеном — должно вернуть 200 и ссылку на пост с картинкой
curl -X POST https://sintaition.sintaris.net/webhook/zerocoder-autopost-image \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <токен>" \
  -d '{"topic": "Тема поста"}'
```
