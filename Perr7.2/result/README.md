# Perr7.2 — SMM-эксперт с ИИ (часть 1). Результат

**Тема:** путешествия и уютные маршруты по Европе.
**Форма сдачи:** расширение работающего ассистента Taris, а не отдельный скрипт.
**Состояние:** реализовано, протестировано (52 теста), развёрнуто на боевом сервере
(версия 2026.8.82) и проверено вживую.

## Что нового появилось по заданию

| Требование задания | Что сделано |
|---|---|
| Генерация текста постов через API ИИ | было раньше — контент-план из 7 постов и готовые посты, с правкой своими словами |
| **Генерация изображения по тексту поста** | **новое:** ИИ описывает сцену → модель изображений рисует → файл хранится на сервере и публикуется вместе с постом |
| **Сбор и отображение статистики публикаций** | **новое:** посты, лайки, просмотры, подписчики, средняя вовлечённость, доля постов с картинкой, публикации по месяцам, популярные темы |
| Интерфейс для работы с постами | веб-приложение (FastAPI + Jinja2) и Telegram-бот — два независимых интерфейса |
| Сохранение данных | PostgreSQL на сервере / SQLite на слабых устройствах, две таблицы |
| Сверх задания | публикация в сообщество ВКонтакте и автоматическое чтение оттуда лайков, просмотров и подписчиков |
