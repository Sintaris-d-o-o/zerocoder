## Что именно проверяется

### T554 — офлайн-проверки расширения

| Тест | Проверяет | Какую ошибку ловит |
|---|---|---|
| `T554a` | таблицы `content_posts` / `content_metrics` заведены **в обеих** базах; вовлечённость не хранится колонкой | схема, попавшая только в SQLite, — это 500 на боевом сервере с PostgreSQL |
| `T554b` | арифметика сводки на числах из задания | подписчики, сложенные вместо максимума, превращают 18 000 читателей в 35 500 |
| `T554c` | путь к картинке не выводит за пределы папки | `../../etc/passwd` в качестве «пути к картинке» |
| `T554d` | генерация возвращает ошибку, а не исключение (провайдер выключен, нет ключа, сеть упала, пустой ответ) | «кнопка не работает» вместо сообщения; 500 на веб-странице |
| `T554e` | описание сцены переживает отказ модели, не тащит служебные `<think>`, и **всегда** несёт тему поста | картинка про дуб в тумане для поста про Рим |
| `T554f` | сохранить, а затем опубликовать — один пост в учёте, а не два | двойной счёт в статистике |
| `T554g` | публикация помечает пост и открывает ряд наблюдений | опубликованный пост, которого нет в статистике |
| `T554h` | разбор строки «245 3200 18000» во всех вариантах записи | числа через запятую или со словами не распознаются |
| `T554i` | все новые маршруты требуют сеанса; картинка отдаётся только владельцу; пустое поле формы не даёт 422 | классическая «молча сломанная форма»: пустое числовое поле → ошибка 422 |
| `T554j` | каждое имя, которое используют шаблоны, действительно передаётся маршрутом | необъявленная переменная в шаблоне — гарантированная 500 |
| `T554k` | все строки интерфейса есть на ru/en/de/sl | кнопка без подписи на одном из языков |

### T_CS — модульные тесты агента (фрагмент нового)

| Тест | Проверяет |
|---|---|
| `T_CS_21` | кнопка «🖼» существует, только если картинку действительно можно создать |
| `T_CS_22` | новая картинка сохраняется в сессии, старый файл удаляется |
| `T_CS_23` | «Убрать картинку» удаляет файл, а не только ссылку на него |
| `T_CS_24` | ВКонтакте предлагается как адрес публикации, только если пользователь его настроил |
| `T_CS_25` | публикация во ВКонтакте отправляет картинку вместе с постом |
| `T_CS_26` | пользователь, настроивший только ВКонтакте, считается готовым к публикации |
| `T_CS_27` | введённые числа сохраняются именно тому посту, который был выбран |
| `T_CS_28` | пустой список постов сообщает об этом, а не показывает нули |
| `T_CS_29` | пост длиннее 1024 символов уходит как фото + отдельное сообщение (ограничение Telegram) |

### T_CW — браузерные тесты (боевой сервер)

Каждый виджет не «находится на странице», а **используется**: форма отправляется, числа
читаются обратно со страницы, кнопка удаления нажимается, поля заполняются пустыми и
мусорными значениями, чужая картинка запрашивается по прямой ссылке.

| Тест | Проверяет |
|---|---|
| `T_CW_15` | со страницы контент-стратега есть переход в статистику, и она открывается |
| `T_CW_16` | сохранённый черновик появляется строкой в таблице показателей |
| `T_CW_17` | введённые лайки/просмотры/подписчики сохраняются и читаются обратно с сервера |
| `T_CW_18` | пустые и некорректные значения полей не ломают страницу (нет 422) |
| `T_CW_19` | показатели для несуществующего поста отклоняются |
| `T_CW_20` | кнопка «Удалить» действительно убирает пост из статистики |
| `T_CW_21` | картинка из чужого пространства имён не отдаётся (404) |
| `T_CW_22` | страница статистики недоступна без входа |

## Как запустить

```bash
# модульные тесты агента
PYTHONPATH=src python -m pytest src/tests/test_content_strategy.py -q

# офлайн-проверки расширения
python src/tests/test_voice_regression.py --test t_content_agent

# браузерные тесты (нужен доступ к работающему серверу)
PICO_BASE_URL=<адрес> PICO_ADMIN_USER=<логин> PICO_ADMIN_PASS=<пароль> \
  python -m pytest src/tests/ui/test_ui.py::TestContentStatisticsWebUI -q
```
