# Домашнее задание

## Задача
Разработать первую часть приложения для генерации контента, повторяя логику преподавателя, но с другой тематикой. В качестве темы выберите, например, путешествия, кулинарию, моду, спорт, IT-образование или технологии для дома.

Нужно создать рабочий MVP, в котором:
- генератор текста постов работает через OpenAI API;
- генератор изображений создаёт визуал по текстовому описанию;
- собирается и выводится статистика публикаций;
- приложение оформлено в виде простого интерфейса для работы с постами.


## Выбранная тема
Рекомендуемая тема: путешествия и уютные маршруты.

Пример идеи проекта:
- генерация текста постов про города, отели, маршруты, советы туристам;
- генерация картинок: «красивый вид на Рим утром», «поездка по горам в Альпах», «пляжный отдых в Сейшелах»;
- статистика: лайки, просмотры, подписчики, публикации по месяцам.


### 2. Генерация текста постов через OpenAI API
Реализуйте функцию, которая отправляет запрос к OpenAI API и получает текст для поста.

### 3. Генерация изображений
После генерации текста поста создавайте изображение на основе полученного описания. Это можно сделать через OpenAI Image API либо через другой сервис генерации изображений.

Если у вас используется другой сервис, можно хранить изображение локально и показывать его в шаблоне.


### 4. Сбор и отображение статистики публикаций
Нужно добавить метрики, которые будут отслеживаться для постов:
- лайки;
- просмотры;
- подписчики;
- количество постов;
- средний уровень вовлечённости;
- популярные темы.

Пример данных:

```python
posts = [
    {
        "title": "Рим с утра до вечера",
        "likes": 245,
        "views": 3200,
        "followers": 18000,
        "engagement": 7.8,
    },
    {
        "title": "Секреты путешествий по Порту",
        "likes": 198,
        "views": 2600,
        "followers": 17500,
        "engagement": 6.9,
    }
]
```

В интерфейсе можно показать:
- карточки с общей статистикой;
- список последних постов;
- таблицу с метриками;
- простую диаграмму или график.


## Требования к проекту
1. Использовать Python.
2. Подключить OpenAI API.
3. Приложение должно быть оформлено в виде минимум одного простого интерфейса (Flask / FastAPI / Streamlit).
4. Реализовать генерацию текста и изображения для постов.
5. Добавить статистику и вывод результатов пользователю.
6. Сохранить данные в JSON, БД или память приложения.


## Минимальный функционал MVP
- Ввод темы поста.
- Генерация текста поста.
- Генерация изображения по тексту.
- Сохранение поста в список.
- Отображение статистики по постам.
- Показ карточки с лайками, просмотрами и подписчиками.


## Рекомендации по оформлению
- Используйте понятные названия функций: generate_post, generate_image, save_post, calculate_stats.
- Разделяйте код на модули: сервисы и модели.
- Выводите данные в простой и красивый интерфейс.
- Храните ключ API в переменной окружения.


## Формат сдачи
Необходимо:
1. Создать проект.
2. Реализовать первую часть функционала.
3. Запустить приложение и проверить работу.
4. Сделать скриншоты кода и интерфейса.
5. Оформить результат в виде отчёта или презентации.

## Итог
Главная цель задания — показать, как можно собрать приложения с генерацией текста и изображений на основе ИИ, а также визуализировать метрики публикаций. Важно не просто повторить код преподавателя, а адаптировать тему под собственный проект.

Если вы делаете проект в другой тематике, главное — сохранить принцип архитектуры и логику работы приложения.
