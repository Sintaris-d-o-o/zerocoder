# zerocoder

Публичные решения заданий курса Zerocoder («Промпт-инжиниринг 2.0», university.zerocoder.ru).
Каждое задание — в отдельной папке, названной по номеру задания.

## Задания

- [Perr3.5](Perr3.5-multimodal-assistant/) — мультимодальный ассистент «Описание товаров по фото»: голос/текст + фото товара → готовое продающее описание
- [Perr3.6](Perr3.6-nutri-curator/) — паспорт MVP мультимодального ассистента-куратора курса нутрициолога «Вита»
- [Perr4.1](Perr4.1-taris-custdev-sheets/) — кастдев в Google Sheets + ChatGPT: формулы `GPT`/`GPT_LIST`/`GPT_TRANSLATE`/`GPT_EXTRACT` на примере платформы «Тарис»
- [Perr4.4](Perr4.4/) — бот-ассистент «Тарис» для приёма заявок в Telegram и на сайте (общая логика диалога для обоих каналов)
- [Perr6.2](Perr6.2/) — разбор LangChain Cookbook (онбординг-бот на RAG) и применение схемы к проекту «Тарис»
- [Perr6.5](Perr6.5/) — локальный RAG-консультант по ювелирным изделиям (FAISS + ChromaDB + Llama 3.2 через Ollama)
- [Perr7.1](Perr7.1/) — n8n-сценарий анализа записей звонков: локальная транскрибация, сравнение GPT и локальной модели, выгрузка результатов в Google Sheets
