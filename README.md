# zerocoder

Публичные решения заданий курса Zerocoder («Промпт-инжиниринг 2.0», university.zerocoder.ru).
Каждое задание — в отдельной папке, названной по номеру задания.

## Задания

- [Perr6.5](Perr6.5/) — локальный RAG-консультант по ювелирным изделиям (FAISS + ChromaDB + Llama 3.2 через Ollama)
