## Тема урока

Ты создашь полноценный веб-сервис автоматического прескоринга кандидатов:

— загрузка вакансии и PDF-резюме;
— интеллектуальный анализ через GPT;
— расчет итогового score по 100-балльной шкале;
— выделение сильных и слабых сторон кандидата;
— хранение и сравнение результатов в интерфейсе.

В результате у тебя будет рабочий HR-инструмент, который можно адаптировать под реальные бизнес-процессы или добавить в портфолио как практический кейс автоматизации.

## Домашнее задание
Реализуй собственную систему автоматического прескоринга кандидатов на основе материалов урока.

Что нужно сделать:
1️⃣ Реализовать анализ резюме
Настроить подключение к API (через .env).
Организовать получение строго структурированного JSON со следующими полями: score, strengths, weaknesses, missing_skills, summary.
Обеспечить обработку и “ремонт” JSON при необходимости.
2️⃣ Реализовать парсинг PDF
Использовать pdfplumber для извлечения текста.
Очистить текст (удалить лишние переносы, пробелы, шум).
Ограничить объем текста (например, до 6000 символов).
3️⃣ Реализовать систему оценки
Разделить оценку на:
hard skills
experience
soft skills
Настроить веса (сумма = 100%).
Реализовать расчет итогового балла по взвешенной формуле.
4️⃣ Создать интерфейс
Реализовать веб-интерфейс на Streamlit.
Добавить:
поле для ввода вакансии;
загрузку PDF-резюме;
ввод имени кандидата;
отображение итогового score;
вывод сильных и слабых сторон.
5️⃣ Реализовать хранение истории
Добавить сохранение результатов (JSON или CSV).
Обеспечить возможность просмотра нескольких кандидатов.
