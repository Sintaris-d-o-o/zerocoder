# Демонстрация задания 8.1

## Что показывать

Всё необходимое для проверки лежит в этой папке репозитория:

1. [результаты.md](результаты.md) — полный отчёт: датасет, обучение, сравнение
   моделей, выводы, сверка с заданием.
2. [code/normassistent_finetuning_full.py](code/normassistent_finetuning_full.py) —
   весь Colab-ноутбук, экспортированный в один читаемый файл (все ячейки по
   порядку: §3 данные → §4 генерация и валидация → §4.5 визуализация датасета →
   §5 обучение → §6–§7 проверка и графики → §9 экспорт в Ollama).
3. [results/](results/) — артефакты обучения:
   - `loss_curve.png` — кривая обучения (train/val loss);
   - `metric_compare.png` — базовая vs дообученная модель по 5 метрикам;
   - `uc_lang_heatmap.png` — качество по сценариям × языкам;
   - `metrics.json` — все числа сравнения.
