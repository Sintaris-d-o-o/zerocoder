# PErr10.3. Генератор видео. Часть 1

Оригинал урока: `university.zerocoder.ru`, модуль 10.
Полный текст урока — в файле [PErr10.3. Генератор видео. Часть 1 (new).pdf](PErr10.3.%20Генератор%20видео.%20Часть%201%20(new).pdf) (27 стр.).

## Тема урока

Генерация видео по текстовому описанию через сервис-посредник **Proxy API**.

Что разбирается:

1. **Зачем нужен сервис-посредник.** Один API-ключ даёт доступ к моделям разных компаний
   (OpenAI, Google, ElevenLabs) — не нужно заводить отдельный аккаунт у каждого провайдера.
   Запросы идут на серверы в России, обходные схемы не требуются. Плата — надбавка около
   5–10 % к стоимости запроса.
2. **Регистрация и ключ.** Ключ показывается **один раз в момент создания** — посмотреть его
   повторно нельзя, можно только выпустить новый. Сразу сохраняется в `.env`.
3. **Работа через библиотеку `openai`.** Используется стандартный клиент OpenAI, но с другим
   адресом сервера (`base_url`). Код и логика не меняются.
4. **Асинхронная генерация видео.** Модель SORA: видео не создаётся мгновенно, задача сначала
   стоит в очереди, затем обрабатывается, затем рендерится в MP4.

Три ключевых эндпоинта: **создание видео**, **получение статуса генерации**, **скачивание
готового файла**. Всего их пять — есть ещё список видео и удаление.

Порядок работы всегда один:

1. отправка запроса на генерацию;
2. периодическая проверка статуса (`queued` → `in_progress` → `completed`);
3. загрузка готового файла после завершения.

Промпт определяет визуальный стиль, атмосферу, объекты, движение камеры и освещение.

## Домашнее задание

1. Доработай скрипт для генерации видео через Proxy API, используя **собственный промпт**
   (описание видео, отличное от примера эксперта с чашкой кофе).
2. Протестируй генерацию с длительностью **4 секунды**, проверь статус через `test.py` и
   сохрани MP4-файл.
3. В качестве домашнего задания пришли скриншоты:
   - написанного кода с твоим промптом;
   - терминала с прогресс-баром и статусом (`queued` → `complete`);
   - сгенерированного видео (первые/последние кадры или QR-код для скачивания).
