# Задание 10.3 — концепция и план

## Что просят

1. Доработать скрипт генерации видео через Proxy API, используя собственный промпт — не пример
   эксперта с чашкой кофе.
2. Проверить генерацию длительностью 4 секунды, проверить статус через `test.py`, сохранить
   MP4-файл.
3. Прислать скриншоты кода, терминала с прогресс-баром и статусами, и самого видео.

## Что делаем

Генератор коротких роликов по нашей теме — управление сертификатами медицинских изделий.
Три собственных промпта: документы на столе, лаборатория контроля качества, панель контроля
сроков действия сертификатов.

Промпты написаны на английском намеренно: модели генерации видео обучены преимущественно на
английских описаниях и понимают их точнее. Это ровно тот приём, о котором говорил урок 9.1 —
перевод на более «ресурсный» язык.

## Как работает генерация видео

Через сервис-посредник Proxy API, используя стандартную библиотеку `openai` с другим адресом
сервера. Код от этого не меняется.

Генерация асинхронная и долгая:

1. Создание задачи — в ответ приходит идентификатор.
2. Опрос статуса: `queued` → `in_progress` → `completed`. Видео сначала стоит в очереди, потом
   обрабатывается, потом рендерится в файл.
3. Скачивание готового MP4.

## Почему два файла, а не один

Задание прямо требует проверять статус через `test.py`. Это не формальность: генерация видео
занимает минуты, и держать окно терминала открытым всё это время неудобно. Разделение
позволяет запустить генерацию, закрыть окно, а позже отдельной командой посмотреть статус и
забрать готовый файл.

- `video_generator.py` — запуск генерации, ожидание с прогресс-баром, скачивание.
- `test.py` — проверка доступа, статус задачи по идентификатору, слежение до готовности со
  скачиванием, список последних задач.

## Что делаем сверх урока

1. **Прогресс-бар в терминале** — задание требует скриншот с прогрессом, поэтому показываем
   полосу, процент, статус и прошедшее время в одну строку.
2. **Запись пути статусов.** Рядом с видео сохраняется файл с промптом, моделью, длительностью
   и полной цепочкой статусов — по нему видно, сколько задача стояла в очереди.
3. **Понятные ошибки.** Отдельно объясняются нехватка средств на балансе, неверный ключ и
   неправильный адрес сервиса.
4. **Потолок ожидания** 15 минут: если задача застряла в очереди, скрипт не висит бесконечно.
5. **Тесты без обращения к платному сервису.** Генерация видео стоит заметных денег, поэтому
   вся логика проверяется на подменённом клиенте.
6. **Режим `--dry-run`** — показывает запрос, ничего не отправляя.

## План тестирования

- **Без ключа (бесплатно):** параметры запроса, включая длительность 4 секунды; цикл опроса
  проходит все статусы; неудачные статусы превращаются в ошибку; потолок ожидания срабатывает;
  скачанный файл начинается с сигнатуры MP4; пустой ответ отвергается; имя файла безопасно для
  Windows; промпт не содержит примера эксперта; прогресс-бар рисуется правильно; все четыре
  режима `test.py` работают.
- **С ключом:** генерация ролика на 4 секунды, проверка статуса через `test.py`, сохранение MP4.

## Что нужно для запуска

Ключ Proxy API: `PROXYAPI_KEY` в `.env`, при необходимости `PROXYAPI_BASE_URL`. Ключ выдаётся
один раз при создании и требует пополненного баланса. Генерация видео — самая дорогая операция
из трёх заданий модуля.
