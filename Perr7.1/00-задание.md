# Задание: Создание сценария в n8n для анализа записей звонков

## 1. Создание сценария в n8n

- Используй платформу **n8n** для создания сценария, который будет:
  - Собирать записи звонков с e-mail
  - Транскрибировать их
  - Анализировать текст на предмет выявления бизнес-выводов
- Можешь использовать шаблон сценария от преподавателя (в дополнительных материалах к уроку). Используй для транскрибации модели, библиотект и узлы n8n для обработки звука локально. без использования Chat GPT API

## 2. Работа с записями звонков

- Источники записей:
  - Звонки из дополнительных материалов к уроку
  - ИЛИ создай свои записи (используй нейросети для создания текстов разговоров и озвучки, если нужен кейс для портфолио)
- Отправь записи на выбранный для данного кейса e-mail

## 3. Транскрибация и анализ

- Запусти процесс транскрибации и анализа текста
- Выявляй бизнес-выводы, такие как:
  - Возражения клиентов
  - Tone of voice (тон голоса)
  - Другие метрики на твое усмотрение

## 4. Представление результатов

- Опубликуй ссылку на **Google-таблицу**, куда отправлялись данные из n8n
- Таблица должна содержать результаты анализа всех обработанных записей звонков
- Ссылку разместить в качестве домашнего задания
