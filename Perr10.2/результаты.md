# Задание 10.2 — что сделано и какие результаты

## Статус

**Веб-приложение написано, запущено и заснято на скриншоты.** 16 тестов проходят. Интерфейс

Сайт на Flask, который превращает генератор из задания 10.1 в готовый инструмент: пользователь
вводит название компании, выбирает стиль и формат, получает логотип и скачивает его.

Скриншоты интерфейса (сняты автоматически через браузер без окна):

- [results/screenshots/02_галерея.png](results/screenshots/02_галерея.png) — галерея

## Что именно доработано

Задание требует **доработать** приложение, а не повторить. Список доработок против версии
эксперта:

| Доработка | Что было | Что стало |
|---|---|---|
| **Генерация в отдельном потоке** | браузер ждёт ответа до двух минут, страница выглядит зависшей | страница сразу показывает прогресс, время и число проверок статуса |
| **Сохранение результата** | картинка живёт только в браузере, при обновлении теряется | файл сохраняется на диск вместе с промптом и зерном |
| **Галерея** | нет | последние работы видны на главной странице |
| **Повтор с тем же зерном** | нет | кнопка подставляет прежнее зерно, чтобы получить вариацию того же логотипа, а не другой рисунок |
| **Форматы** | только квадрат | логотип, иконка, баннер 16:9, вертикальная обложка 9:16 — меняется и соотношение сторон, и текст запроса |
| **Запрет надписей** | нет | к промпту автоматически добавляется «без текста, без букв»: модели рисуют на логотипах нечитаемые псевдобуквы |
| **Ошибки** | показывается код ответа сервера | объясняется, что именно не так |
| **Работа без ключа** | невозможна | режим `--demo` рисует заглушки, интерфейс можно показать и протестировать бесплатно |

## Как собирается промпт

Из четырёх частей, каждая со своей ролью:

1. **Что рисуем** — зависит от формата: логотип, иконка, баннер или обложка.
2. **Стиль** — один из шести (минимализм, деловой, медтех, технологичный, документ и печать,
   винтаж).
3. **Свободное описание пользователя** — необязательное.
4. **Технический хвост** — запрет надписей, белый фон, чёткие края.

Пример для названия «SINTARIS», стиля «медтех» и описания «щит с галочкой»:

> Логотип компании «SINTARIS». медицинская тематика, чистые линии, бирюзовый и синий,
> ассоциации с точностью, безопасностью и заботой о здоровье. щит с галочкой.
> без текста, без букв и цифр, на белом фоне, чёткие края.

## Найденный и исправленный дефект

При первом же скриншоте обнаружилось, что блок «Отправляем запрос…» виден сразу при загрузке
страницы, хотя должен быть скрыт. Причина оказалась в правилах оформления: у правила с
идентификатором приоритет выше, чем у класса, поэтому `display: flex` перебивало класс
«скрыто». Исправлено, в коде оставлено объяснение, чтобы правило не убрали обратно.

Это ровно тот случай, ради которого стоит снимать скриншот, а не полагаться на тесты: тесты
проверяли ответы сервера и не видели, как страница выглядит.

## Что проверено тестами

| Проверка | Зачем |
|---|---|
| Промпт собирается из всех частей | название, стиль, описание и запрет надписей на месте |
| Промпт меняется вместе с форматом | логотип, баннер и обложка описываются по-разному |
| Все шесть стилей и четыре формата дают осмысленный промпт | 24 сочетания |
| Пустое и слишком длинное название отвергаются | с понятным сообщением |
| Нечисловое зерно отвергается | вместо падения сервера |
| Полный путь: запуск, ожидание, скачивание | включая проверку, что файл действительно JPEG |
| Зерно возвращается в ответе | иначе нельзя повторить удачный вариант |
| Результат попадает в галерею | и виден на главной странице |
| Имя файла безопасно для Windows | проверяется на названии с кавычками, слешем и двоеточием |
| Ошибка API превращается в сообщение | вместо белого экрана |

## Что нужно, чтобы получить настоящие логотипы

Тот же ключ Yandex Cloud, что и для задания 10.1: `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в файле
`.env`. Порядок получения описан в [результатах задания 10.1](../Perr10.1/результаты.md).

После этого:

```powershell
cd Perr10.2
python app.py            # без --demo
```

Открыть http://127.0.0.1:5000, ввести название, выбрать стиль, нажать «Сгенерировать».
Логотипы сохранятся в `results/logos/`, и я добавлю их в отчёт со скриншотами.
