# Демонстрация задания 10.2

## Что показывать проверяющему

1. [результаты.md](результаты.md) — отчёт, таблица доработок и сверка с заданием.
2. [results/screenshots/](results/screenshots/) — **скриншоты веб-приложения**: форма ввода и
   галерея.
3. [app.py](app.py) — сервер: запуск задачи в отдельном потоке, опрос статуса, отдача файла.
4. [templates/index.html](templates/index.html), [static/](static/) — интерфейс.
5. [tests/test_app.py](tests/test_app.py) — 16 тестов без обращения к платному API.
6. `results/logos/` — сгенерированные логотипы (появятся после получения ключа).

## Как запустить

```powershell
cd Perr10.2
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

.\.venv\Scripts\python.exe -m pytest tests -q   # тесты, бесплатно
.\.venv\Scripts\python.exe app.py --demo        # интерфейс без ключа, бесплатно
.\.venv\Scripts\python.exe app.py               # рабочий режим (нужен ключ)
```

Открыть http://127.0.0.1:5000.

**Режим `--demo`** рисует заглушки вместо обращения к API: интерфейс можно показать и
протестировать целиком, ничего не потратив. На странице при этом висит предупреждение, чтобы
заглушку нельзя было принять за настоящий результат.

## Как сняты скриншоты

Автоматически, браузером без окна — команда есть в истории проекта:

```powershell
msedge --headless=new --window-size=1200,1000 --screenshot="results\screenshots\01_форма.png" "http://127.0.0.1:5055/"
```

Так скриншот получается одинаковым при каждом повторе и не зависит от размера окна.
