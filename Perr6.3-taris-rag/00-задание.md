# Задание Perr6.3 — векторная база данных и генерация ответов (RAG)

Курс: Промпт-инжиниринг 2.0. Задание продолжает задание 6.2 (`../Perr6.2/`), где был разобран
пример «New Employee Onboarding Chatbot» из LangChain Cookbook и предложено применить его в проекте
Тарис (онбординг-бот для экспертов и студентов платформы).

## Домашнее задание (дословно, как предоставлено пользователем)

1.
- Создай векторную базу данных.
- Разбей текст на чанки и преобразуй их в векторные представления.
- Используй векторные представления для генерации ответов на запросы.

2. Подготовь краткий текстовый отчет о проделанной работе и приложи скриншоты своего кода.

## Уточнения пользователя

- ~~Текст для базы — база знаний онбординг-бота Тариса~~ (заменено, см. ниже).
- Модели — полностью локально: векторы считает локальная модель эмбеддингов, ответы генерирует
  llama3.2:3b через Ollama. Без облачных API.
- Уточнение после первой версии концепции: вместо новой базы знаний переиспользовать уже
  существующую векторную базу агента-нутрициолога Taris (небольшая подборка текстов).
- Код Taris приватный и не должен быть виден публично (репозиторий zerocoder — публичный).
  Код и тексты Taris используются только локально, в папке `private/` (исключена из git);
  нужны лишь для выполнения задания и скриншотов.
