# Демонстрация — Perr6.3

Код и тексты базы взяты из коммерческого проекта Taris. Поэтому они лежат только на компьютере
автора, в папке `private/`, которая исключена из git. Запустить проект можно только там.
Проверяющему показываем результат скриншотами.

## Что нужно

- Ollama с моделью `llama3.2:3b` (`ollama pull llama3.2:3b`).
- Python-библиотеки: `sentence-transformers`, `sqlite-vec`, `python-docx`, `ollama`.
- Модель векторов `paraphrase-multilingual-MiniLM-L12-v2` скачивается один раз. Дальше всё
  работает без интернета.

## Запуск

```powershell
cd Perr6.3-taris-rag\private\code

# 1. Построить векторную базу: тексты → чанки → векторы → private\kb.sqlite (≈30 секунд)
py build_index.py

# 2. Задать вопрос (флаг --show-chunks дополнительно показывает, какие кусочки нашла база)
py ask.py --show-chunks "Зачем нужна клетчатка и сколько её нужно в день?"

# 3. Режим диалога: вопросы по одному, пустая строка — выход
py ask.py
```

Что попробовать спросить:
- «Почему организм закисляется и как это исправить?»;
- «Чем полезен гель алоэ вера с мёдом?»;
- «Какая погода в Белграде?» — бот должен ответить, что в базе этого нет.

## Как показать проверяющему

1. Приложить к ответу скриншоты из `private/screenshots/` — это скриншоты кода и работы в
   терминале (список — в `результаты.md`). Скриншоты прикладываются вручную, на GitHub их нет.
2. Приложить текст краткого отчёта — раздел «Отчёт для преподавателя» из `результаты.md`.
3. При желании — показать запуск вживую на своём компьютере (команды выше), например при
   демонстрации экрана.
