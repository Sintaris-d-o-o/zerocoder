# Демонстрация и сдача домашнего задания PE4.1

## Что уже готово

Файл [`taris-custdev-sheets.xlsx`](taris-custdev-sheets.xlsx) — три листа с полностью сгенерированным контентом (описание продукта «Тарис», 17 кастдев-пунктов, тесты 9 типов формул, 3 идеи проектов). Контент получен напрямую через OpenAI API (`generate_content.py`), тем же способом, каким работает расширение ChatGPT в Google Таблицах, — можно проверить сгенерировав скрипт заново, если нужно другое описание продукта.

## Что нужно сделать вам в браузере (10–15 минут)

1. **Загрузить файл в Google Таблицы**
   - Откройте [Google Диск](https://drive.google.com/), перетащите туда `taris-custdev-sheets.xlsx`.
   - Дважды кликните на загруженный файл → «Открыть в Google Таблицах» (или ПКМ → Открыть с помощью → Google Таблицы).
   - Google сам превратит файл в обычную Google Таблицу с тремя вкладками: «1. Продукт», «2. Тест формул», «3. Идеи проектов» — это и есть структура, которую просит задание.

2. **Установить расширение ChatGPT**
   - В открытой таблице: меню «Расширения» → «Дополнения» → «Установить дополнения».
   - В поиске введите `chatgpt`, поставьте **«GPT for Sheets™ and Docs™»** (как в уроке) — либо, если хотите бесплатные бонусные токены без своей карты, альтернативу **«GPT for Slides™ Docs™ Sheets™»** (support.gpt.space, 300 000 бесплатных кредитов).
   - При желании можно вставить свой `OPENAI_API_KEY` в настройках расширения (Set API keys) — тогда обработка будет дешевле. Ключ не публикуйте нигде в самой таблице, только в настройках расширения.

3. **Вживую протестировать формулы** (на листе «2. Тест формул»)
   - В столбце D уже есть готовые примеры данных для каждой формулы («Что подставляем»), в столбце E — эталонный результат, который я получил через API.
   - Возьмите любые 4–5 строк, в свободном столбце (например F) введите ту же формулу из столбца B, ссылаясь на данные в D — например `=GPT(D2)`, `=GPT_LIST(D8)`, `=GPT_TRANSLATE(D9;"English")`, `=GPT_EXTRACT(D10;"email")`.
   - Сравните, что выдало расширение, с эталоном в столбце E — результаты не обязаны совпадать дословно (модель отвечает не всегда одинаково), но должны быть похожи по смыслу и формату.
   - Это и есть то самое «протестируй все основные формулы» из задания — только вы делаете это не с нуля, а сверяясь с готовым эталоном.

4. **Заменить формулы на текст** (как просит задание)
   - Для всех ячеек, где вы вписали живые формулы: выделяем ячейку → Ctrl+C → удаляем содержимое → Ctrl+Shift+V (вставить только значение).
   - На листе «1. Продукт» формулы изначально не вставлялись — там сразу готовый текст, ничего менять не нужно.

5. **Открыть доступ и отправить ответ**
   - Кнопка «Настройки доступа» → «Доступным по ссылке» → «Читатель» (или как настроено на курсе).
   - Скопируйте ссылку и вставьте её в поле ответа на странице урока: https://university.zerocoder.ru/pl/teach/control/lesson/view?id=340014348 → «Ваш ответ» → «Отправить ответ».

## Как проверить результат самостоятельно ещё раз (без браузера)

Если захотите пересобрать таблицу (например, с другим описанием продукта):

```
cd Perr4.1-taris-custdev-sheets
python generate_content.py
```

Скрипт использует `OPENAI_API_KEY` из корневого `.env` и модель `gpt-4o-mini` (недорогая, как и рекомендовано в уроке). Результат — обновлённый `taris-custdev-sheets.xlsx` в этой же папке.
