# Концепция и план: кастдев-таблица для платформы «Тарис» (ChatGPT в Google Таблицах)

## 1. Что делаем и зачем

Задание урока — научиться пользоваться расширением ChatGPT в Google Таблицах (оно вставляет ответы нейросети прямо в ячейки по формуле, как обычный `=СУММ()`, только вместо суммы — текст от ChatGPT) и с его помощью прогнать вымышленный продукт через полный кастдев: кто клиент, какие у него боли, кто принимает решение о покупке, какие возражения и как на них отвечать.

За основу продукта берём вашу реальную сферу — платформу **«Тарис»**:

> «Тарис» — платформа для экспертов (авторов онлайн-курсов, коучей, консультантов), которая объединяет в одном месте общение с учениками, обучение (уроки, задания, прогресс) и ведение клиентов (CRM, оплаты, напоминания) — вместо того чтобы вручную склеивать Telegram, Google-документы и таблицы. Дополнительно вы продаёте аудит текущих процессов эксперта и внедрение платформы под его задачи. Целевая аудитория — эксперты, которые ведут собственные курсы и теряют учеников/деньги из-за хаоса в разрозненных инструментах.

Если хотите — можно поправить формулировку перед стартом реализации, сейчас она черновая, собрана из того, что вы описали.

Практическая польза от задания лично для вас: готовая кастдев-таблица по «Тарис» (сегменты, ЛПР, боли, возражения, УТП, речевой модуль) — это не просто оценка за урок, а рабочий черновик, который потом можно использовать в продажах и маркетинге платформы.

## 2. Что мешает сделать всё автоматически — и как обходим

Домашка требует реально открыть Google Таблицу в вашем личном Google-аккаунте, установить платное расширение из Google Workspace Marketplace и прогнать в нём формулы. Это ручные клики в браузере под вашим логином — я не могу нажимать кнопки в чужом браузере и не имею доступа к вашему Google-аккаунту.

Поэтому делим работу так:

- **Я делаю (автоматически, через код и OpenAI API, ключ уже есть в `.env`):**
  - формулирую 17 промптов под «Тарис» — по одному на каждый пункт из задания (сегментация, ЛПР, боли, возражения и т.д.);
  - реально прогоняю эти промпты через ChatGPT (напрямую через API — тот же ChatGPT, что стоит за расширением) и получаю готовые тексты-ответы;
  - тем же способом готовлю примеры для второго листа — «тестирование формул» (GPT, GPT_LIST, GPT_TRANSLATE, GPT_EXTRACT и т.д.) с готовыми результатами для сверки;
  - придумываю 3 идеи проектов для третьего листа;
  - собираю всё в один Excel-файл (.xlsx) с тремя листами строго по структуре задания (1 — продукт, 2 — тест формул, 3 — идеи).
- **Вы делаете руками в браузере (10–15 минут):**
  1. Загружаете готовый .xlsx-файл в свой Google Диск и открываете его — Google сам превратит его в Google Таблицу с тремя вкладками.
  2. Ставите расширение GPT for Sheets (или аналог с бесплатными кредитами, как в уроке) через «Расширения → Дополнения → Установить дополнения».
  3. На листе «Тестирование формул» своими руками запускаете 4–5 формул (`=GPT(...)`, `=GPT_LIST(...)`, `=GPT_TRANSLATE(...)`, `=GPT_EXTRACT(...)`) — просто чтобы реально увидеть, как расширение работает, и сравнить результат с тем, что я уже туда вписал. Это и есть то самое «протестируй формулы» из задания, только вы делаете это не с нуля, а на всём готовом.
  4. Меняете формулы на текст результата (Ctrl+C → удалить содержимое → Ctrl+Shift+V), как просят в задании.
  5. Открываете доступ по ссылке и отправляете её как ответ на платформе.

Так вы выполняете задание своими руками (что и требуется для обучения), но не тратите 40+ минут на придумывание 17 промптов и не расходуете лишние платные токены расширения — самая трудоёмкая часть уже готова.

## 3. План реализации по шагам

1. Зафиксировать финальное описание продукта «Тарис» (см. раздел 1) — если поправите формулировку, использую её.
2. Написать скрипт на Python, который:
   - берёт описание продукта и список из 17 пунктов задания;
   - для каждого пункта формирует промпт (по образцу из урока — «Проведи сегментацию клиентов... для [продукт]» и т.п.);
   - отправляет промпт в OpenAI API (используя `OPENAI_API_KEY` из `.env`) и получает ответ;
   - то же самое делает для 4–5 примеров формул урока (`GPT`, `GPT_LIST`, `GPT_TRANSLATE`, `GPT_EXTRACT`) на понятных тестовых примерах;
   - придумывает 3 идеи проектов, где GPT-в-таблицах пригодился бы в вашей реальной работе (например: авто-заполнение базы знаний для клиентов вроде AI-Nutri-Виктория, разбор заявок, генерация контент-плана для соцсетей «Тариса»).
3. Собрать результат в один `.xlsx`-файл с тремя листами (через `openpyxl`), с понятными заголовками колонок (промпт / формула-образец из урока / готовый результат).
4. Положить файл в папку задания (`Perr4.1-taris-custdev-sheets/`).
5. Отдать вам короткую пошаговую инструкцию (в `demo.md`), что делать дальше руками: загрузить файл в Google Диск → открыть как Таблицу → поставить расширение → прогнать несколько формул вживую → заменить формулы на текст → открыть доступ по ссылке → отправить ссылку в ответ на уроке.

## 4. План тестирования

- Автоматическая проверка: скрипт логирует все 17 + тестовые ответы от OpenAI API — проверю, что ни один запрос не завершился с ошибкой и что во всех ответах нет пустых/бессмысленных значений.
- Проверю, что готовый `.xlsx` открывается и содержит ровно 3 листа с ожидаемыми колонками (открою файл и просмотрю содержимое).
- Ручная часть (её тестируете вы, и опишете мне результат): реально прогнать 4–5 формул в самой Google Таблице через расширение и убедиться, что результат в целом похож на то, что я сгенерировал через API (небольшие расхождения в формулировках — это нормально, модели отвечают не дословно одинаково при разных запусках).

## 5. План демонстрации

- В `demo.md` опишу: где лежит готовый `.xlsx`, как за 10–15 минут превратить его в рабочую Google Таблицу с реально протестированными формулами, и как отправить итоговую ссылку как ответ на домашнее задание на university.zerocoder.ru.
- Проверяющий видит обычную ссылку на Google Таблицу с тремя вкладками — как и просит задание, без дополнительных условий доступа с моей стороны.

## 6. Credentials и доступы

Новых ключей заводить не нужно — используем то, что уже есть в `.env`:
- `OPENAI_API_KEY` — для генерации кастдев-текстов и тестовых примеров формул через API (напрямую, в обход платного расширения).

Доступ к Google-аккаунту и установка расширения в Google Таблицах — только вручную вами, я его не запрашиваю и credentials для этого в `.env` не нужны.
