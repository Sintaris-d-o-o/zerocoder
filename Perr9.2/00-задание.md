# PE9.2 Локальное развертывание моделей

Оригинал урока: [PE9.2 Локальное развертывание моделей](https://university.zerocoder.ru/pl/teach/control/lesson/view?id=338667561).
Полный текст урока — в файле [PE9.2 Локальное развертывание моделей.pdf](PE9.2%20Локальное%20развертывание%20моделей.pdf) (27 стр.).

## Тема урока

Модуль 9. Оптимизация затрат на ИИ. Стратегии развертывания ИИ-моделей
9.2 — как выбирать и оценивать GPU для запуска моделей, что такое эмбеддинги и как их
использовать, какие инструменты применять для локального развертывания моделей.

Разделы урока:

1. **GPU, веса и квантизация** — параметры видеокарты (VRAM, ядра CUDA/Stream Processors,
   пропускная способность памяти, энергопотребление); как посчитать требуемую память из
   числа параметров и формата весов (FP32 — 4 байта, FP16/BF16 — 2 байта, INT8 — 1 байт,
   INT4 — полбайта).
2. **Квантизация** — уменьшение объёма модели с минимальной потерей качества; готовые
   квантизованные модели на Hugging Face.
3. **Инференс против обучения** — обучение требует примерно в 5–6 раз больше памяти;
   калькулятор Hugging Face Model Memory Estimator; LoRA как способ сократить требования.
4. **Эмбеддинги** — представление текста вектором фиксированной длины; когда они заменяют
   большую модель (классификация, кластеризация, мультимодальные системы);
   `sentence-transformers`.
5. **Инструменты локального запуска** — Hugging Face + Transformers, Docker (и Docker Hub),
   llama.cpp, KoboldCpp, LangChain, LLM-агенты (AutoGPT, BabyAGI) и бенчмарки их оценки
   (AgentBench, WebArena).

## Домашнее задание

### 1. Оценка системных требований для локального запуска модели

- **Выбор модели:** выберите большую языковую модель, например GPT-3. Модель можно выбрать
  на платформе Hugging Face или в других источниках.
- **Сбор информации о модели:** найдите технические данные о модели — через документацию,
  статьи или официальные ресурсы, такие как Hugging Face.
- **Определение параметров системы:** соберите информацию о следующих параметрах:
  - объём памяти VRAM;
  - количество ядер CUDA/Stream Processors;
  - пропускная способность видеокарты;
  - энергопотребление.
- Всю информацию оформите в документе Google Docs.
- В качестве домашнего задания пришлите ссылку на документ (не забудьте открыть доступ для
  чтения).

### 2. Инструменты для локального развертывания модели

- Внимательно ознакомьтесь с информацией обо всех инструментах, с помощью которых можно
  запускать модели локально.
- Сделайте сравнительную таблицу всех инструментов: опишите минусы и плюсы каждого
  инструмента, для каких задач подходит тот или иной инструмент.
- Всю информацию оформите в виде таблицы в документе Google Документы.
- В качестве домашнего задания пришлите ссылку на документ (не забудьте открыть доступ для
  чтения).
