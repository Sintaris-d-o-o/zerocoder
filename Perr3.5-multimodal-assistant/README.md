# Мультимодальный ассистент «Описание товаров по фото»

Telegram-бот `@sinta_analytic_bot`. Подробности решения — в [01-концепция-и-план.md](01-концепция-и-план.md).

## Установка и запуск

1. Убедитесь, что в файле `../.env` (папка `zerocoder/`) заданы:
   ```
   TELEGRAM_BOT_TOKEN=...
   OPENAI_API_KEY=...
   ```
   Пример структуры — в [.env.example](.env.example).

2. Установите зависимости:
   ```
   python -m pip install -r requirements.txt
   ```

3. Запустите бота:
   ```
   python bot.py
   ```
   В консоли появится сообщение «Бот запущен, ожидаю сообщения...» — значит, всё готово, можно писать боту `@sinta_analytic_bot` в Telegram.

## Как пользоваться

1. Отправьте боту фото товара.
2. Затем — голосовое сообщение (или текст) с деталями: материал, размер, состояние, цена, особенности.
3. Через несколько секунд бот пришлёт готовое текстовое описание товара и озвучит его.

## Тесты

```
python -m pip install pytest
python -m pytest tests/ -v
```

Тесты проверяют формирование промптов и логику «ожидания деталей после фото» без реальных обращений к OpenAI/Telegram (не тратят деньги и не требуют сети).
