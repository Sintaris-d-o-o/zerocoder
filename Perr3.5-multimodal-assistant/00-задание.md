# Этап 1: Выбери бизнес-задачу

Определи одну рутинную задачу из твоей профессиональной сферы, где нужен анализ/генерация контента в разных форматах. Примеры: анализ входящих чеков/счетов, генерация описаний товаров по фото, обработка резюме соискателей, создание визуальных инструкций. Запиши: что именно ассистент должен принимать на вход (голос, фото, PDF) и выдавать на выход (текст, изображение, голосовое).



# Этап 2: Опиши пайплайн (4 блока)

Нарисуй схему или опиши словами последовательность:

Ввод: какой формат данных от пользователя (голосовое с описанием → текст + фото товара).
Обработка: какие модели используешь (STT для голоса, GPT-Vision для фото, LLM для анализа).
Пост-обработка: что добавляешь (TTS для озвучки ответа, генерация изображения).
Вывод: как отдаёшь результат (текст + картинка в Telegram).


# Этап 3: Напиши системные промпты

Составь 2–3 промпта для ключевых этапов:

Промпт для анализа входных данных ("Извлеки из фото чека сумму, дату, магазин").
Промпт для генерации ("Создай продающий текст для товара на основе описания").
Промпт для пост-обработки ("Оформи ответ как структурированный отчёт: ключевые факты + рекомендация"). Протестируй их мысленно или в чате с GPT.


# Этап 4: Реализуй прототип

Создай Telegram-бота через BotFather (получи токен).
Напиши простой скрипт (или псевдокод): при получении голоса/фото → обработай через OpenAI API → верни ответ. Если кодинг не твой — опиши логику в 10–15 предложениях, как если бы нанимал разработчика.


# Этап 5: Протестируй и проанализируй

Протестируй на 2–3 реальных примерах из твоей работы. Запиши:

Что сработало идеально.
Где возникли ошибки/задержки (неестественный голос, неточные детали на изображении).
Как улучшить (другие модели, доработка промптов). В 5–7 предложениях опиши, сколько времени/денег сэкономит такой ассистент в месяц.
