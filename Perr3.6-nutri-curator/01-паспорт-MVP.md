# Паспорт MVP: ассистент-куратор курса нутрициолога

## Название и цель

**Рабочее название:** «Вита» — ассистент-куратор курса нутрициолога Виктории.

**Цель:** отвечать клиентам курса на вопросы по материалам программы (детокс-протокол, здоровье кишечника, снятие хронического стресса, метод тарелки, продукция LR) и помогать применять эти знания на практике — например, собрать меню на день из того, что реально есть в холодильнике.

## Кто пользователь и что он присылает (Этап 1)

Пользователь — клиент курса нутрициолога Виктории, уже проходящий или недавно завершивший программу (например, детокс-протокол), у которого по ходу дня возникают практические вопросы. Он присылает ассистенту голосовой или текстовый вопрос по теме курса («как выйти из хронического стресса?», «можно ли мне картофель на протоколе?») либо фото — например, содержимое холодильника или страницу материалов курса, если непонятен конкретный пункт. В ответ ассистент должен выдавать не общие фразы из интернета, а конкретную рекомендацию, основанную именно на материалах курса Виктории: чек-лист, план меню на день, объяснение с указанием противопоказаний, — оформленную так, чтобы её было удобно сохранить и использовать в течение дня.

## Пайплайн MVP (4 блока)

**1. Ввод данных.** Клиент пишет боту в Telegram текстовое или голосовое сообщение с вопросом, при необходимости прикладывает фото (холодильник, полка с продуктами, страница материалов курса).

**2. Обработка.**
- Если вопрос голосовой — **STT (OpenAI Whisper)** переводит его в текст.
- Если приложено фото — **GPT-Vision (GPT-4o)** распознаёт содержимое: список продуктов на фото холодильника, либо текст на фото документа.
- **Поиск по базе знаний курса** (детокс-протокол, кишечник, чек-лист по стрессу, метод тарелки, справочник LR): по вопросу клиента находятся релевантные фрагменты материалов — без этого шага ассистент будет отвечать общими фразами, а не тем, чему реально учит Виктория.
- **LLM (GPT-4o)** объединяет вопрос клиента, найденные фрагменты базы знаний и факты с фото (если есть) и формирует ответ.

**3. Пост-обработка.**
- Структурирование ответа по понятным блокам (шаги чек-листа; меню по приёмам пищи — завтрак/обед/ужин).
- Проверка на противопоказания: если тема касается детокс-протокола или пищевых пауз — ассистент обязан явно упомянуть ограничения из материалов курса (например, диабет, беременность) и мягко порекомендовать свериться с Викторией при хронических заболеваниях.
- (опционально) **Генерация изображения (DALL·E)** — наглядная карточка «меню на день» по методу тарелки, если ответ содержит план питания.

**4. Вывод.** Бот отправляет в Telegram текстовый ответ (чек-лист / рекомендация / меню), при необходимости — с приложенной карточкой-инфографикой.

## Выбор формата: визуальный

MVP спроектирован как **визуальный** сценарий (работа с фото/документами и выдача текст + изображение), с сохранением голоса только как удобного способа задать вопрос. Аргументы:

1. Сценарий «фото холодильника → меню на день» технически возможен только через анализ изображения — без него эта часть задачи вообще не решается, поэтому визуальный канал обязателен, а не опционален.
2. Ответы ассистента — это чек-листы, меню по приёмам пищи, списки продуктов с дозировками; такую информацию удобнее один раз прочитать, сохранить и пересмотреть в течение дня, чем один раз прослушать в голосовом сообщении и забыть детали.
3. Клиенты курса уже привыкли получать материалы Виктории в виде текстовых конспектов, чек-листов и PDF — текстовый формат ответа продолжает этот же привычный стиль, а не вводит новый.
4. Голосовой ввод вопроса при этом остаётся — печатать длинный вопрос на ходу неудобно, поэтому голос сохраняется как канал ввода, а не вывода.

## Ключевые промпты

**Промпт для анализа входных данных (фото):**
> «Ты — ассистент нутрициолога. Внимательно посмотри на фото. Если это фото продуктов (холодильник, полка, стол) — перечисли все узнаваемые продукты и их примерное количество. Если это фото документа или страницы материалов курса — точно перепиши текст с неё. Пиши только то, что реально видно на фото, ничего не додумывай.»

**Промпт для формирования итогового ответа:**
> «Ты — ассистент-куратор курса нутрициолога Виктории. Отвечай на вопрос клиента, опираясь только на приведённые ниже материалы курса и, если есть, на список продуктов с фото. Если по теме вопроса в материалах есть противопоказания или ограничения — обязательно укажи их явно. Если информации в материалах недостаточно для точного ответа — честно скажи об этом и порекомендуй уточнить у Виктории лично; не выдумывай факты, которых нет в материалах. Отвечай простым, дружелюбным языком, структурируй ответ по пунктам.
>
> Материалы курса: {релевантные фрагменты базы знаний}
> Продукты на фото (если есть): {результат анализа фото}
> Вопрос клиента: {вопрос}»

**Промпт для генерации изображения (визуальный MVP):**
> «Создай наглядную инфографику-карточку "Меню на день" по методу тарелки: раздели тарелку на секции — белки, сложные углеводы, овощи и клетчатка, полезные жиры — с подписанными примерами блюд из предложенного меню. Стиль: чистый, светлый, в спокойных зелёно-бежевых тонах, дружелюбный для мессенджера, без мелкого текста.»

## Ожидаемый результат для типовых запросов

**Запрос 1 (текст/голос): «Как выйти из хронического стресса?»**
Ассистент находит фрагмент чек-листа по выходу из хронического стресса в материалах курса и возвращает клиенту структурированный пошаговый чек-лист (конкретные шаги и рекомендации из материалов Виктории, а не общие советы из интернета), без изображения — здесь текстового чек-листа достаточно.

**Запрос 2 (фото + текст): «У меня вот такие продукты [фото холодильника]. Что приготовить на день?»**
Vision распознаёт продукты на фото (например: яйца, авокадо, куриное филе, гречка, овощи). LLM, опираясь на метод тарелки и правила детокс-протокола (если клиент сейчас на нём), собирает меню на день (завтрак/обед/ужин) именно из того, что есть у клиента, с коротким объяснением выбора и пометкой, каких продуктов не хватает для баланса по методу тарелки. При необходимости прикладывается карточка-инфографика тарелки на день.

## Экономия и развитие

Такой ассистент экономит время в первую очередь самой Виктории и её команде: сейчас одни и те же вопросы («что можно есть», «как пережить день пищевой паузы», «что приготовить из того, что есть дома») клиенты задают лично в переписке, и на однотипные ответы уходит время, которое можно потратить на сложные случаи и работу с новыми клиентами. Если ассистент закрывает даже 30–40% типовых вопросов, это может освобождать несколько часов в неделю кураторской работы. Для клиентов это тоже ценно: ответ приходит мгновенно, а не после ожидания в переписке, что повышает вероятность того, что человек не сорвётся с протокола из-за одного нерешённого практического вопроса. В следующей версии стоит сделать полноценный поиск по базе знаний (векторный поиск по всем материалам вместо передачи их целиком в промпт), чтобы ассистент точнее находил нужный фрагмент даже в большой базе. Также полезно добавить знание о том, на каком этапе протокола находится конкретный клиент, чтобы ответы были персональными, а не общими. Для чувствительных тем (детокс, голодание, противопоказания) стоит предусмотреть эскалацию сложных или пограничных вопросов на живого куратора, а не полагаться только на автоответ ассистента.
