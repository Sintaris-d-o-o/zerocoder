# Выпускной проект курса Zerocoder

Оригинал: `university.zerocoder.ru`. Текст задания вставлен пользователем в чат.

Указание пользователя: **ничего не придумываем** — выпускным проектом становится уже
существующая платформа **Taris** (репозиторий `sintaris-pl`). Задача — описать её по
плану задания, опираясь на реальные материалы и наработки.

## Текст задания

Ты можешь создать проект, который отличается от ранее выполненных, или объединить
несколько идей в новый проект. Главное, чтобы проект соответствовал теме:
автоматизация бизнес-решений с помощью ИИ.

### Определение проблемы и идеи проекта

Придумай проблему, которую будет решать твой проект, и сформулируй основную идею.

Например:

- Проблема: Компании тратят много времени на создание индивидуальных текстов для
  сотрудников, работающих с клиентами в различных ситуациях.
- Решение: Автоматизировать процесс создания таких текстов на основе базы знаний компании.
- Идея: Создание нейроассистента для отдела продаж, который генерирует
  персонализированные сценарии обзвона клиентов под различные задачи.

### Выбор инструментов и технологий

Подбери подходящие инструменты для реализации проекта:

- Зерокод-платформы: Make, Zapier, Albato для интеграции процессов и автоматизации задач.
- Программирование: Python для обработки данных, настройки API и использования
  нейросетевых моделей.
- Можно комбинировать подходы: использовать Python для настройки логики и подключения
  нейросетей, а зерокод для интеграции с внешними сервисами.
- Также используй дополнительные возможности, такие как дообучение нейросетей,
  использование LangChain, облачное развертывание моделей и другие технологии, если это
  необходимо для реализации твоего проекта.

### Начало разработки

- Определи основные функции проекта: взаимодействие с пользователем, работа с API,
  генерация текста или данных на основе нейросетей, интеграция с базой знаний.
- Разработай проект, включив выбранные функции и технологии.

### Тестирование

- Проверь работу проекта: взаимодействие с пользователем, корректность генерации данных,
  стабильность интеграций.
- Устрани ошибки и оптимизируй проект.

### Реализация взаимодействия

Выбери удобный формат для использования проекта:

- Чат-бот (Telegram, WhatsApp, VK).
- Виджет на сайте.
- Приложение, разработанное на Python или зерокоде или другое.

**Важно:** Проект должен включать работу с нейросетевыми моделями и API, быть
завершённым и готовым к практическому использованию.
