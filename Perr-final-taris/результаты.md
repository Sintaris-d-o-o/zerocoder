# Выпускной проект — что сделано и результаты

## Коротко

Выпускной проект — **Taris**, наша действующая экспертная платформа на базе знаний компании.
Она отвечает на вопросы клиентов и сотрудников строго по документам компании, показывает
источники и честно говорит, когда ответа в документах нет. Работает в Telegram, в браузере
и голосом, использует облачные и локальные нейросети и n8n для связи с внешними сервисами.

Новый код под выпускной проект не писался: задача была описать существующий продукт по плану
задания. Главный документ — [02-описание-проекта.md](02-описание-проекта.md).

## Как собирали описание

- Позиционирование — вариант А из концепции: «экспертная платформа на базе знаний компании».
- Историю «с чего началось» написали со слов автора: боты для нутрициолога, по охране труда
  и для текстов; запрос рынка на автоматизацию, хранение данных у себя, независимость от
  платформ и точность без выдумок.
- Факты о Taris брали **только из уже сданных и открытых отчётов** заданий курса (1.5, 1.6,
  6.2, 6.3, 7.2–7.4, 8.1, 8.2, 9.2, 10.4–10.6). У каждой цифры в описании указано задание-источник.
- Закрытый репозиторий Taris для этой работы не читали. Шесть фактов, которые есть только в
  концепции, помечены знаком ⚑ и вынесены в отдельный список в конце описания: провайдеры
  нейросетей, LangChain, языки, число тестов, журнал ошибок, текущая версия.

## Проверка описания

- Каждое утверждение сверено с отчётом-источником. При сверке нашлись и исправлены три
  неточности черновика:
  - бот по охране труда был ошибочно привязан к заданию 1.6 — теперь это указано со слов
    автора;
  - распознавание речи было ошибочно приписано OpenAI — на самом деле это локальный
    faster-whisper;
  - схема онбординг-бота из 6.2 была описана как «перенесена в Taris» — на самом деле она
    только предложена.
- В тексте нет кода, паролей, адресов серверов, имён клиентов.
