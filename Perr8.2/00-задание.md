# PE8.2 LLM Fine-tuning. Особенности дообучения

Оригинал урока: `university.zerocoder.ru` (модуль 8 «Дообучение нейросетей», урок 8.2).
Полный текст урока — в файле [PE8.2 LLM Fine-tuning. Особенности дообучения.pdf](PE8.2%20LLM%20Fine-tuning.%20Особенности%20дообучения.pdf) в этой папке.

## Тема урока

- Настройка LLM для дообучения: выбор **токенизатора** (обязательно тот же, что у исходной
  модели), класс `transformers.Trainer` / `SFTTrainer`, форматы данных (диалоговый и
  инструкционный).
- **Гиперпараметры обучения**: `output_dir`, `learning_rate`, `num_train_epochs`, `fp16`,
  `per_device_train_batch_size` (и что делать при out-of-memory).
- **Метрики качества**: функция потерь неинтерпретируема, поэтому нужны понятные метрики —
  accuracy / precision / recall / F1 для классификации; **ROUGE** (суммаризация), BLEU,
  METEOR, BERTScore, Perplexity — для генерации. Библиотека Hugging Face `evaluate`,
  а также кастомные метрики (пример — средняя длина ответа).
- **PEFT** (Parameter-Efficient Fine-Tuning): selective methods, reparameterization (**LoRA**),
  additive methods (**Prompt Tuning**). Разбор LoRA на числах: 32 768 → 4 608 параметров (−86 %).
