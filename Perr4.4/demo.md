# Демонстрация

Один и тот же ассистент работает в двух каналах и пишет заявки в одну общую таблицу [requests.csv](requests.csv).

## Telegram-бот

1. Откройте Telegram, найдите бота `@sinta_analytic_bot` (ссылка: `t.me/sinta_analytic_bot`).
2. Напишите `/start` — бот поздоровается и спросит, что вас интересует.
3. Отвечайте на вопросы бота вымышленными данными (имя, телефон — как требует дисклеймер задания).
4. Когда бот соберёт всё необходимое, он оформит заявку и подтвердит это сообщением.

Живой тест проведён: бот собрал две реальные заявки (#4 «Инна», #5 «Олег Сергеев») с вымышленными данными — записи есть в [requests.csv](requests.csv). Скриншоты переписки нужно добавить в папку `screenshots/` (не приложены в этой версии).

### Доступ для проверяющего

Бот работает, пока запущен скрипт `bot.py` на компьютере автора задания (у бота нет постоянного сервера — это учебный прототип). Два варианта показать результат:

- **Вживую.** Проверяющему достаточно написать боту `@sinta_analytic_bot` в момент, когда автор задания держит бота запущенным (по договорённости о времени).
- **Через скриншоты переписки.** Если проверяющий заходит не в момент, когда бот запущен — нужны скриншоты реального диалога (добавить в `screenshots/`).

## Сайт-чат

1. Установите зависимости и запустите сервер — инструкция в [README.md](README.md).
2. Откройте в браузере `http://localhost:8000`.
3. Ведите диалог так же, как в обычном чате — ассистент сам уточнит недостающие данные.
4. Когда заявка оформлена, в чате появится подтверждение «Заявка сохранена в общую таблицу ✓».

Живой тест проведён программно (3 диалога через API) — записи #1–#3 в [requests.csv](requests.csv), интерфейс дополнительно стилизован под фирменный виджет Sintaris. Скриншот чата в браузере нужно добавить в папку `screenshots/` (не приложен в этой версии).

### Доступ для проверяющего

Сайт — локальный прототип без постоянного публичного адреса. Проверяющему нужно:
- либо самостоятельно запустить сервер по инструкции из [README.md](README.md) (займёт 2 минуты — ключи API уже не понадобятся свои, если это делает автор задания на своём компьютере);
- либо посмотреть скриншоты переписки, приложенные к заданию.

## Таблица заявок

Файл [requests.csv](requests.csv) — общий для обоих каналов, колонка «Источник обращения» показывает, откуда пришла заявка. Открывается в Excel или Google Таблицах (импорт CSV). На момент сдачи в таблице 5 реальных тестовых записей (3 с сайта, 2 из Telegram). Скриншот таблицы нужно добавить в папку `screenshots/` (не приложен в этой версии).
