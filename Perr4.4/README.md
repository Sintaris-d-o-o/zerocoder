# Бот-ассистент — заявки на консультацию (Telegram + сайт)

Один и тот же ассистент (общая логика диалога в [assistant.py](assistant.py)) работает в двух каналах — Telegram-бот `@sinta_analytic_bot` и локальный сайт-чат — и пишет заявки в одну общую таблицу [requests.csv](requests.csv). Подробности решения — в [01-концепция-и-план.md](01-концепция-и-план.md).

## Установка

1. Убедитесь, что в файле `../.env` (папка `zerocoder/`) заданы:
   ```
   TELEGRAM_BOT_TOKEN=...
   OPENAI_API_KEY=...
   ```
   Пример — в [.env.example](.env.example).

2. Установите зависимости:
   ```
   python -m pip install -r requirements.txt
   ```

## Запуск Telegram-бота

```
python bot.py
```

В консоли появится «Бот запущен, ожидаю сообщения...» — можно писать боту `@sinta_analytic_bot` в Telegram.

## Запуск сайта

```
python website/website_app.py
```

Откройте в браузере `http://localhost:8000`.

## Как пользоваться (любой из каналов)

1. Напишите, что вас интересует (например: «интересует CRM для учеников» или «сколько стоит»).
2. Ассистент по ходу разговора уточнит имя и телефон.
3. Когда данных достаточно, ассистент сам оформит заявку и подтвердит это.
4. Заявка появится новой строкой в [requests.csv](requests.csv) — файл можно открыть в Excel или Google Таблицах.

## Таблица заявок в формате Excel

CSV уже открывается в Excel напрямую, но для более удобного просмотра (цветной заголовок, ширина колонок, перенос текста) есть готовый файл [requests.xlsx](requests.xlsx). Чтобы обновить его после новых заявок:

```
python export_xlsx.py
```

## Тесты

```
python -m pytest tests/ -v
```

Тест проверяет запись в общую таблицу (`storage.py`) — что строки корректно дописываются, ID увеличивается по порядку, кириллица не портится — без реальных обращений к OpenAI/Telegram.
