# Test №1 — Простейший контент-завод (n8n + OpenAI + Google Sheets)

## 1. Цель
Собрать workflow в n8n, который автоматически:
1. Отслеживает новую строку в Google Sheets.
2. Берет `source_url` из строки.
3. Парсит контент страницы.
4. Отправляет текст в OpenAI (`gpt-4o-mini`) для генерации поста.
5. Записывает результат обратно в ту же строку таблицы.
6. Публикует/обновляет workflow в n8n по `N8N_WORKFLOW_ID` из `.env`.

## 2. Концепт (MVP)
Источник данных: Google Sheets (добавили строку -> триггер).

Конвейер:
`Google Sheets Trigger` -> `Validate Row` -> `HTTP Request (source_url)` -> `Extract/Clean Text` -> `OpenAI (gpt-4o-mini)` -> `Update Row in Google Sheets`.

Статусы обработки:
- `new` — строка готова к обработке.
- `processing` — workflow начал обработку.
- `done` — пост успешно создан.
- `error` — ошибка обработки (текст ошибки пишем в колонку `error`).

## 3. Что должно быть готово до реализации
1. Доступ к n8n (UI + API).
2. Доступ к Google Sheets OAuth в n8n.
3. OpenAI API key.
4. В `.env` должны быть заполнены:
   - `N8N_API_BASE`
   - `N8N_API_KEY`
   - `N8N_WORKFLOW_ID`
   - `OPENAI_API_KEY`
   - `OPENAI_MODEL=gpt-4o-mini`

## 4. Структура Google Sheets
Используйте таблицу:
<https://docs.google.com/spreadsheets/d/1UB8m4kZM1ohHOgTQ_ub-bYXHsKg2Uk1P-f1hw1hB2I4/edit?gid=0#gid=0>

Рекомендуемые колонки (лист `Sheet1`):
1. `id`
2. `source_url`
3. `topic`
4. `status`
5. `raw_text`
6. `post_text`
7. `processed_at`
8. `error`

Минимальный вход для запуска: `source_url`, `status=new`.

## 5. Workflow в n8n (пошагово)

### Шаг 1. Создать workflow
1. Открыть n8n -> `New workflow`.
2. Назвать: `test1-content-factory`.

### Шаг 2. Node: Google Sheets Trigger
1. Добавить `Google Sheets Trigger`.
2. Credential: ваш Google account.
3. Spreadsheet ID: `1UB8m4kZM1ohHOgTQ_ub-bYXHsKg2Uk1P-f1hw1hB2I4`.
4. Sheet: `gid=0` (обычно `Sheet1`).
5. Event: new/updated row (в зависимости от вашей версии n8n).

### Шаг 3. Node: IF (валидация входа)
Условие для продолжения:
1. `source_url` не пустой.
2. `status` равен `new`.

Если условие `false` -> завершить без действий.

### Шаг 4. Node: Google Sheets (Update row -> processing)
1. Обновить ту же строку.
2. Поставить `status=processing`.
3. Очистить `error`.

### Шаг 5. Node: HTTP Request (скачать страницу)
1. Method: `GET`.
2. URL: `{{$json.source_url}}`.
3. Response format: `String`.
4. Timeout: 30-60 сек.

### Шаг 6. Node: HTML Extract (или Code)
Цель: получить основной текст статьи.

Вариант A (быстрее): `HTML Extract`
1. Извлечь `title`, `p` из основного контейнера.
2. Склеить в одно поле `raw_text`.

Вариант B (универсально): `Code` node
1. Удалить служебные блоки (`script`, `style`, меню, футер).
2. Оставить осмысленный текст.

### Шаг 7. Node: OpenAI (HTTP Request)
Рекомендуется через `HTTP Request`, чтобы модель бралась из `.env`.

1. URL: `https://api.openai.com/v1/responses`
2. Method: `POST`
3. Headers:
   - `Authorization: Bearer {{$env.OPENAI_API_KEY}}`
   - `Content-Type: application/json`
4. Body (JSON):

5. Из ответа взять финальный текст в поле `post_text`.

### Шаг 8. Node: Google Sheets (Update row -> done)
Обновить ту же строку:
1. `raw_text` = очищенный текст.
2. `post_text` = текст от модели.
3. `status` = `done`.
4. `processed_at` = текущая дата/время.
5. `error` = пусто.

### Шаг 9. Error branch
Добавить ветку ошибок (через `Error Trigger` или отдельный error-path):
1. `status=error`
2. `error=<сообщение ошибки>`
3. `processed_at=<timestamp>`

## 6. Логика против дублей
Чтобы строка не обрабатывалась повторно:
1. Запускать только строки со `status=new`.
2. При старте сразу ставить `processing`.
3. После успеха ставить `done`.

## 7. Проверка (тест-кейсы)
1. Добавить строку с валидным URL и `status=new` -> получить `post_text` и `status=done`.
2. Добавить невалидный URL -> `status=error`, заполнено поле `error`.
3. Проверить, что строка со `status=done` не обрабатывается повторно.

## 8. Публикация workflow по `N8N_WORKFLOW_ID` из `.env`

### Вариант через UI
1. Открыть workflow `test1-content-factory`.
2. Скопировать/установить ID как `N8N_WORKFLOW_ID`.
3. Нажать `Activate`.

### Вариант через API (PowerShell)
Ниже пример обновления существующего workflow:

```powershell
$envFile = Get-Content .env
$map = @{}
foreach ($line in $envFile) {
  if ($line -match '^[A-Za-z_][A-Za-z0-9_]*=') {
    $k, $v = $line -split '=', 2
    $map[$k] = $v
  }
}

$headers = @{
  'X-N8N-API-KEY' = $map['N8N_API_KEY']
  'Content-Type' = 'application/json'
}

# 1) Сначала экспортируйте JSON workflow из n8n UI в файл workflow.json
$workflowJson = Get-Content -Raw workflow.json

# 2) Обновить workflow по ID из .env
Invoke-RestMethod -Method Put `
  -Uri "$($map['N8N_API_BASE'])/v1/workflows/$($map['N8N_WORKFLOW_ID'])" `
  -Headers $headers `
  -Body $workflowJson
```

После обновления убедитесь, что workflow активен (`active=true`).
