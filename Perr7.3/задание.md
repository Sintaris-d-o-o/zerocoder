# Домашнее задание: SMM-ассистент на Flask

## Описание задания

Создать базовое веб-приложение с использованием Flask, реализующее функционал генерации постов и изображений с последующей автопубликацией в ВКонтакте. Приложение должно поддерживать регистрацию и авторизацию пользователей.

## Требования

### 1. Аутентификация и авторизация
- Регистрация новых пользователей
- Вход в систему
- Защита маршрутов (только для авторизованных пользователей)
- Выход из системы

### 2. Генерация контента
- Генерация текстовых постов на основе заданных параметров
- Генерация изображений (использовать API или готовые инструменты)
- Сохранение истории сгенерированного контента

### 3. Интеграция с ВКонтакте
- Подключение к VK API
- Автопубликация постов в группу/паблик
- Сохранение статуса публикации

### 4. Интерфейс
- Страница логина/регистрации
- Дашборд с формой для генерации постов
- Просмотр истории публикаций
- Управление настройками ВК-интеграции

## Используемые технологии
- Flask
- SQLite
- VK API SDK
- Werkzeug (для хеширования паролей)


## Задачи реализации
1. Настроить базовую структуру Flask приложения
2. Реализовать систему аутентификации
3. Создать модели БД для пользователей и постов
4. Реализовать функции генерации текста и изображений
5. Подключить VK API для автопубликации
7. Добавить валидацию форм
8. Настроить сессии и cookies
