# Perr7.3 — SMM-ассистент на Flask. Подтверждение реализации

**Что это за папка.** Задание Perr7.3 требует веб-приложение с регистрацией и входом,
генерацией постов и картинок, автопубликацией во ВКонтакте, историей публикаций и
управлением настройками ВК. **Всё это уже реализовано** в ассистенте Taris — часть
задолго до этого задания (аутентификация, роли, веб-интерфейс), часть в рамках
предыдущей работы Perr7.2 (генерация картинок, статистика, публикация во ВКонтакте).

Новой разработки в этой папке нет. Это документация-подтверждение: где именно в коде
живёт каждый пункт задания, как устроена архитектура, и как проверяющий может убедиться
в этом сам — на работающем сервере.

**Развёрнуто и проверено:** TariStation1, версия **2026.8.83**.

## Короткий ответ по заданию

| Требование задания | Состояние | Где реализовано |
|---|---|---|
| Регистрация новых пользователей | ✅ | `GET/POST /register` → `security/bot_auth.py: create_account()` |
| Вход в систему | ✅ | `GET/POST /login` → `verify_password()` + `create_token()` |
| Защита маршрутов | ✅ | `_get_current_user()` в каждом маршруте + `_agents_role_guard()` |
| Выход из системы | ✅ | `GET /logout` — cookie удаляется |
| Генерация текстовых постов по параметрам | ✅ | `POST /agents/content/plan` и `/post` → `_generate_content()` |
| Генерация изображений | ✅ | `POST /agents/content/image` → `core/bot_images.py` |
| Сохранение истории контента | ✅ | таблицы `content_posts` + `content_metrics`, плюс заметки |
| Подключение к VK API | ✅ | `features/bot_content_vk.py` (wall.post, photos.*, groups.getById) |
| Автопубликация в группу | ✅ | `POST /agents/content/publish` c `target=vk` |
| Сохранение статуса публикации | ✅ | `content_posts.status / published_at / channel / external_url` |
| Страница логина/регистрации | ✅ | `login.html`, `register.html` (+ восстановление пароля) |
| Дашборд с формой генерации | ✅ | `/` (дашборд) и `/agents/content` (форма) |
| Просмотр истории публикаций | ✅ | `/agents/content/stats` |
| Управление настройками ВК | ⚠️ частично | есть в Telegram-канале интерфейса; в вебе — только чтение и подсказка |
| Валидация форм | ✅ | серверная: типы FastAPI + проверки в маршрутах |
| Сессии и cookies | ✅ | подписанный JWT в httpOnly-cookie, роль перечитывается из БД |
| SQLite | ✅ | адаптер SQLite (по умолчанию); на боевом сервере — PostgreSQL, тот же код |
| Flask | ⚠️ иначе | FastAPI + Jinja2 — тот же шаблон приложения, обоснование в `результаты.md` |
| Werkzeug для хеширования | ⚠️ иначе | bcrypt, work factor 12 (`bot_auth.py`) |

Два пункта отмечены «иначе» и один — «частично». Это осознанные отличия, каждое разобрано
в `результаты.md`; ни одно из них не отменяет требуемую функцию.
