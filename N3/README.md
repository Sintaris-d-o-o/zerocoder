# N3 — ранние задания курса на n8n (перенос из отдельного репозитория)

Эта папка — перенос репозитория `stas-ka/zerocoder` в общий репозиторий курса.
Здесь собраны **ранние задания**, посвящённые автоматизации в **n8n** (задания 1.2, 2.1, Тест №1 и N3).
Более поздние задания курса лежат в папках `Perr*` в корне репозитория.

Внутренняя структура сохранена такой же, какой она была в исходном репозитории.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `ДОМАШКИ/` | Тексты заданий, концепции и отчёты по каждой домашней работе |
| `workflows/` | Экспортированные сценарии n8n (`.json`) и таблица с результатами |
| `docs/` | Runbook'и — пошаговые инструкции «как это запустить и проверить» |
| `scripts/` | PowerShell-скрипты публикации сценариев в n8n через API |
| `.github/` | Инструкции и навыки для GitHub Copilot, использовавшиеся при работе над заданиями |

## Настройка перед запуском скриптов

Скрипты в `scripts/` читают настройки из файла `.env`, который должен лежать **в этой папке**
(`N3/.env`). Самого `.env` в репозитории нет и не будет — он содержит секреты.

1. Скопируйте `.env.example` в `.env`.
2. Заполните значения своими (ключи API, адрес сервера, идентификаторы воркфлоу).

`.env` исключён корневым `.gitignore`, поэтому случайно закоммитить его не получится.

## Что намеренно не перенесено

Общий репозиторий курса — **публичный**, поэтому при переносе было исключено следующее:

- **Файл `.env`** с рабочими ключами (OpenAI, n8n API, Telegram-бот, доступ по SSH).
  Вместо него добавлен `.env.example` — только имена переменных, без значений.
- **Резюме кандидатов** (`Ковалёв`, `Мельников`, `Шоплик` — PDF и DOCX) и **скриншоты писем
  с резюме**. Это персональные данные живых людей, их нельзя публиковать.
- **Тестовые данные внутри `n3-hr-assistant.workflow.json`** (блок `pinData`): там лежали
  письма кандидатов с именами, телефонами и адресами почты. Сама логика сценария
  (все 27 нод и связи между ними) сохранена полностью — удалены только приложенные
  тестовые письма.

Всё это по-прежнему доступно в заархивированном репозитории `stas-ka/zerocoder`.
