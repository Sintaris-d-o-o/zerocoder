Что разбирается:

5. **Код на Python** — функция запроса, опрос статуса операции, декодирование base64 и
   сохранение изображения.

### Как устроен запрос к Yandex ART (из урока)

Генерация асинхронная: сначала создаётся операция, затем её статус опрашивается в цикле.

| Шаг | Запрос |
|---|---|
| 1. Запуск генерации | `POST https://llm.api.cloud.yandex.net/foundationModels/v1/imageGenerationAsync` |
| 2. Проверка статуса | `GET https://llm.api.cloud.yandex.net:443/operations/{id}` в цикле с паузой |
| 3. Результат | поле `response.image` — изображение в base64, декодируется и сохраняется в файл |

Тело запроса:

```python
{
    "modelUri": f"art://{folder_id}/yandex-art/latest",
    "generationOptions": {
        "seed": seed,                                  # None — каждый раз новое изображение
        "aspectRatio": {"widthRatio": "1", "heightRatio": "1"}
    },
    "messages": [{"weight": "1", "text": prompt}]      # weight — вес промпта
}
```

Заголовки: `Content-Type: application/json` и `Authorization: Api-Key {ключ}`.
Префикс `Api-Key` — у Яндекса; у других сервисов бывает `Bearer`.

Параметр `aspectRatio` задаёт форму: `1:1` для логотипов, `16:9` для широкого формата,
`9:16` для вертикального.
