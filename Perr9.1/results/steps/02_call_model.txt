--- H1 [hard] Which MDR classification rule applies to software that calculates insulin doses for a patient, which class results, and why?
дежурный (gemma4:12b, локально): 'hard' → hard   [18.7 с, 209+2 токенов, $0.00000]
ответ модели уровня 'hard' (gpt-5, openai):
- Rule: MDR Annex VIII, Chapter III, Rule 11 (software).
- Class: Class IIb.
- Why: The software provides information used to take decisions for therapeutic purposes (insulin dosing). Under Rule 11, such software is class IIa by default, but is up-classified to class IIb when those decisions may cause a serious deterioration of a person’s state of health (e.g., severe hypo-/hyperglycaemia from an incorrect insulin dose). Only if the decisions may cause death or irreversible deterioration would it be class III (Annex VIII, Ch. III, Rule 11, second and third indents).
